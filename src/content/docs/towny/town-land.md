自分たちの町をつくるなら、建てたい場所だけでなく、毎日の維持費も考えてみましょう。
仲間と役割を相談しておくと、町づくりを続けやすくなります！

## 町をつくる

1. `/towny prices`で設立費用などを確認します
2. ほかの町から十分に離れた、取得できる場所を探します
3. 町の中心にしたい区画で`/town new 町名`を入力します
4. 費用や確認画面が出たら内容を読み、案内に従います
5. `/town`と`/town plots`で設立結果を確認します

`/town create 町名`も同じ設立操作です。
すでに町に所属している、名前が重複している、必要なお金がない、取得禁止の場所にいる場合などは設立できません。

設立後は[町の銀行](../economy/)に運営資金を入れ、[住民の招待](../town-management/)や建築ルールの案内を進めましょう

:::tip[町を作った後、何から始める？]
まずは`/town`で町の情報を見て、運営資金と建築する範囲を確認しましょう。
導入準備中の[チュートリアル](../../start/tutorial/#町を作った後の例)では、この流れをゲーム内でも順番に案内します。
入金や領土の取得は、費用と必要な範囲を確かめてから進めてください。
:::

## 領土を広げる

町の領土取得は、個人の`/plot claim`とは違う操作です。
取得権限のある町長・役職の人が使います。

| コマンド | 取得範囲 |
| --- | --- |
| `/town claim` | 今いる区画を町の領土にする |
| `/town claim auto` | 取得できる周辺範囲を自動選択する |
| `/town claim rect 半径` | 四角い範囲をまとめて取得する |
| `/town claim circle 半径` | 円状の範囲をまとめて取得する |
| `/town claim fill` | 領土に囲まれた未取得の穴を埋める取得を行う。距離や処理上限などの条件あり |
| `/town claim outpost` | 本体から離れた前哨地を取得する。設定で許可されている場合のみ |
| `/town buy bonus 区画数` | 町が持てる土地の追加枠を購入する。実際の土地取得は別に行う |

例えば新しい区画の上で`/town claim`を実行し、`/town here`で町の領土になったことを確認します。
まとめて取得すると合計費用も増えます。
取得可能数、町への隣接、ほかの町との距離、ワールド・バイオームの制限などが条件になります。

## 領土を手放す

| コマンド | 解除範囲 |
| --- | --- |
| `/town unclaim` | 今いる区画を町の領土から外す |
| `/town unclaim rect 半径` | 四角い範囲を外す |
| `/town unclaim circle 半径` | 円状の範囲を外す |
| `/town unclaim all` | 町の領土全体を解除するための操作 |

:::caution[領土を手放すと、町の保護から外れます]
領土を外すと、その土地は町の保護を受けなくなります。
町の中心区画や住民所有地などは、設定・状態によって解除できません。
土地の再生設定が有効なサーバーでは、建築物にも影響する可能性があります。
解除時の案内を読み、必要な荷物の移動を済ませてから実行してください。
:::

## 町の中心・移動先を決める

| コマンド | できること |
| --- | --- |
| `/town set homeblock` | 今いる自分の町の区画を、町の中心区画にする |
| `/town set spawn` | 町のスポーンを現在地に設定する。中心区画内などの条件あり |
| `/town set outpost` | 今いる前哨地のスポーン位置を設定する |
| `/town set spawncost 金額` | 町スポーンへの移動料金を設定する。料金上限などの条件あり |
| `/town toggle public [on/off]` | 外部から利用する町スポーンの公開状態を切り替える |

`public`は町の建築権限を全員に開放する設定ではありません。
公開しても敵対関係やサーバーの移動制限などが適用されます。
スポーンは床と頭上の空間を確保し、初めて訪れた人も分かりやすい場所にしましょう。

## 隣の町へ区画を譲る

`/town cede plot 町名`で、今いる区画を別の町へ譲る申請をします。
町同士の位置関係や所有状態、受け手の取得可能数などの条件があります。
相手側の確認・承諾が必要なので、先に双方の町長で場所を相談してください。

## 町ごと売る・買う

| コマンド | できること |
| --- | --- |
| `/town forsale 価格` | 自分の町を売り出す。`/town fs 価格`も同じ |
| `/town notforsale` | 町の売り出しを取り消す。`/town nfs`も同じ |
| `/town buytown 町名` | 売り出されている町を購入する。所属・費用などの条件あり |

これは区画ひとつの売買ではなく、町の管理を引き継ぐ操作です。
町の銀行、土地、住民、維持費を確認し、表示された確認手順に従ってください。

## 町を合併する・削除する

| コマンド | できること |
| --- | --- |
| `/town merge 相手の町名` | 自分の町を残す形で、相手の町へ合併を申し込む。双方の町長による手続きが必要 |
| `/town delete` | 自分の町を削除するための操作。町長向け |
| `/town reclaim` | 廃墟状態の元の町を復興する。廃墟機能、復興可能期間、立場、費用などの条件あり |
| `/town takeoverclaim` | 条件を満たす土地の奪取取得。サーバーがその仕組みを許可している場合のみ |

:::caution[mergeは町そのものをまとめる操作です]
**コマンドを実行した側の町が残り、指定した相手の町は吸収されます。**
例えば自分の町が`Sakura`のときに`/town merge Hinode`を実行すると、相手の承諾後に残るのは`Sakura`です。`Hinode`という別の町は残りません。

合併前に、両方の町長で次の点を確認してください。

- **お金**：合併費用、町の銀行残高、相手の町に借金がある場合の負担
- **土地**：引き継ぐ領土、前哨地、取得上限、合併後の維持費
- **住民と役職**：新しい所属先と役職。残る町で無法者に指定されている住民は、その町へ加入できません
- **運営ルール**：残る町の税金・権限・所属国家と、合併後に見直す設定

合併費用がある場合は、申請前に金額の確認が表示されます。
合併には、相手の町長による承諾が必要です。
どの町をどちらへ統合する確認なのか、表示された町名を読んでから返事をしてください。
合併を取り消す通常コマンドはないため、試しに承諾せず、住民への説明を済ませてから進めましょう。
:::

:::caution[町の削除は、町を抜ける操作とは違います]
`/town delete`は町そのものを削除するため、ほかの住民や土地の保護にも影響します。
自分だけ抜けたい場合は、[町からの脱退](../residents/#町を抜ける)を確認してください。
廃墟化や復興は設定次第なので、「削除しても必ず元に戻せる」とは考えないでください。
:::

確認が届いたら、対象を確かめてから[確認コマンド](../reference/#確認と取り消し)を使います
