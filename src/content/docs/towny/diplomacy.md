国家の外交権限を持つ国王・役職が使う操作です。
関係を変える前に、相手の国家と方針を相談しましょう。
同盟は土地の`ally`権限やチャット、移動条件にも関わります。

## 同盟を申し込む

| コマンド | できること |
| --- | --- |
| `/nation ally add 国家名` | 国家に同盟を申し込む |
| `/nation ally add -国家名` | 送信した同盟申請を取り消す |
| `/nation ally sent [ページ]` | 送った申請を見る |
| `/nation ally received [ページ]` | 届いた申請を見る |
| `/nation ally accept 国家名` | 同盟申請を承諾する |
| `/nation ally deny 国家名` | 同盟申請を断る |
| `/nation ally remove 国家名` | 同盟関係を解除する |
| `/nation allylist [国家名]` | 現在の同盟を確認する |
| `/town allylist [町名]` | 町の所属国家に関わる同盟の一覧を見る |

例えば`/nation ally add Hinode`で申し込み、相手が承諾したら`/nation allylist`で結果を確認します。
同盟申請は相手の返事が必要です。
同盟にしただけで全区画を共有するわけではありませんが、`ally`に許可している操作の対象が増えるため、土地の設定も確認してください。

## 敵対関係を指定する

| コマンド | できること |
| --- | --- |
| `/nation enemy add 国家名` | 国家を敵対先として登録する |
| `/nation enemy remove 国家名` | 自分の国家側の敵対指定を解除する |
| `/nation enemylist [国家名]` | 敵対先を確認する |
| `/town enemylist [町名]` | 町の所属国家に関わる敵対先を見る |

敵対指定は、双方が同時に同じ設定になる操作ではありません。
自分が解除しても、相手側の指定が残る場合があります。
戦争の開始・勝敗・占領のルールは別の仕組みによるため、敵対に登録しただけで戦争が始まるとは案内していません。

## 特定の町を国家への加入対象から外す

| コマンド | できること |
| --- | --- |
| `/nation sanctiontown add 町名` | その町を国家の制裁対象に指定する |
| `/nation sanctiontown remove 町名` | 制裁指定を解除する |
| `/nation sanctiontown list [国家名]` | 制裁対象の町を確認する |

制裁された町は、その国家への加入を制限されます。
サーバー全体のBANや、町の土地を削除する操作ではありません。
自分の国家を対象にした操作権限が必要です。

## 申請や変更ができないとき

対象の国家・町が存在するか、すでに同じ関係になっていないか、申請が期限切れでないかを確認してください。
権限、申請数上限、関係の制限、追加プラグインなどで拒否される場合もあります。
連打せず、表示された理由を確認してからやり直しましょう。
