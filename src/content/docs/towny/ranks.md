町への招待や建築、国家の外交などを、仲間に分担してもらうための仕組みが**ランク（役職）**です。
町の役職と国家の役職は別々に付けます。同じ名前でも、任せられる操作は異なります。

このページは、日ノ本鯖のTowny権限設定をもとに案内しています。
役職があっても、土地の所有者・所属・機能の有効無効など、コマンドごとの条件を満たす必要があります。

:::tip[まずは、お願いしたい仕事から選びましょう]
町への招待だけなら `recruiter`、町有地の建築なら `builder` が候補です。
名前が強そうな役職をまとめて付けるより、担当する仕事に合わせて選ぶと安心ですね！
:::

## 所属で決まる立場と、後から付ける役職

| 立場 | 役割と決まるタイミング |
| --- | --- |
| 一般プレイヤー | 町への所属にかかわらず適用。町・国家の一覧や役職一覧を確認できる |
| 町の住民 | 町に参加したとき。自分の土地の管理、町への入金、町チャットなどが使える |
| 町長<br>`mayor` | 町の代表になったとき。町・区画を幅広く管理する。交代は専用コマンドで行う |
| 国王<br>`king` | 国家の代表になったとき。国家を幅広く管理する。交代は専用コマンドで行う |
| 追加の役職 | 町長・国王などが付けたとき。建築担当や招待担当など、その役職の操作が増える |

追加の役職は、住民としての権限に**足される**ものです。
町と国家の役職を両方持つことや、複数の役職を持つこともできます。
役職を1つ外しても、ほかの役職や別の権限設定で許可されている操作は残る場合があります。

`mayor` や `king` は、`rank add` で付ける追加役職ではありません。
代表者を交代するときは、[町長の引き継ぎ](../town-management/#町長を引き継ぐ)・[国王の引き継ぎ](../nations/#名前首都案内の設定)を確認してください。

## 町の役職

付ける相手は**自分の町の住民**です。
コマンドには、役職欄の英字を使います。

| 役職 | 追加される主な権限 |
| --- | --- |
| `builder`<br>建築担当 | 町有地でブロックを置く・壊す |
| `recruiter`<br>招待担当 | 住民を町へ招待する |
| `treasurer`<br>会計記録担当 | 町の銀行履歴を見る |
| `helper`<br>操作の手伝い | 町有地で、Townyの `switch` に当たるブロック操作をする |
| `sheriff`<br>保安担当 | 町の牢屋への収監・釈放・牢屋一覧の確認、収監に関する権限 |
| `assistant`<br>町長補佐 | 領土の取得、住民の招待、区画関連の広い操作、町の公開設定の切り替え、`vip`・`helper` の付与や解除など。住民税の免除も付く |
| `comayor`<br>共同町長 | 町・区画の幅広い管理、自分の町での建築・操作など。住民税の免除も付く。制限は下の注意書きを確認 |
| `vip`<br>VIP | このTowny設定では、追加のTowny操作権限なし |
| `donator`<br>寄付者 | このTowny設定では、追加のTowny操作権限なし |

表の日本語の呼び方は説明用です。日本語の呼び方をコマンドに入力するわけではありません。

:::caution[builderは、住民の家を自由に編集する役職ではありません]
`builder` が追加するのは、住民個人の土地ではなく**町有地**での建築・破壊の権限です。
町の管理コマンドや、チェスト・ドアなどの操作権限までまとめて付くわけではありません。
個人の家を手伝う場合は、持ち主と相談して[土地の権限](../permissions/)を設定しましょう。
:::

:::note[会計担当でも、出金できるとは限りません]
町の `treasurer` が追加するのは `/town bankhistory` の権限だけです。
この役職だけでは、町の銀行からの出金や税金の設定変更は許可されません。
また、`vip`・`donator` という名前だけで、免税や特典が付く設定にもなっていません。
:::

### 共同町長に任せる前に

`comayor` は、出金・領土解除・住民の管理など、町全体に影響する操作を含む広い役職です。
町長本人になるわけではなく、今回の役職設定では次の権限が明示的に除かれています。

- 新しい町・国家の作成
- `comayor`・国家の `coking` の付与や解除
- `/town set mayor` による町長の交代

町長本人を条件にしている追加プラグインなど、権限だけでは使えない操作もあります。
建築や招待だけを頼みたい場合は、`builder` や `recruiter` から選びましょう。

## 国家の役職

付ける相手は**自分の国家に属する町の住民**です。
町の役職を付けても、国家の役職は自動では付きません。

| 役職 | 追加される主な権限 |
| --- | --- |
| `diplomat`<br>外交担当 | 同盟の申請・承認・解除など、同盟に関する操作 |
| `treasurer`<br>会計記録担当 | 国家の銀行履歴を見る |
| `helper`<br>加盟の手伝い | 町を国家へ招待する |
| `assistant`<br>国王補佐 | 町の招待、同盟・敵対関係の操作、ほかの国家への入金、国家の `helper` の付与や解除 |
| `coking`<br>共同国王 | 国家の幅広い管理、ほかの国家への入金。制限は下の注意書きを確認 |

国家の `treasurer` も、追加されるのは `/nation bankhistory` の権限だけです。
国家の銀行から出金する権限は、この役職だけでは付きません。
`diplomat` の担当は同盟関係で、敵対関係の操作まで含むわけではありません。

### 共同国王に任せる前に

`coking` は、国家の資金・加盟する町・外交関係など、国家全体に関係する広い役職です。
国王本人になるわけではなく、今回の役職設定では次の権限が明示的に除かれています。

- 新しい町・国家の作成
- 町の `comayor`・国家の `coking` の付与や解除
- `/town set mayor` による町長の交代
- `/nation set king` による国王の交代
- `/nation set capital` による首都の変更

:::caution[町の役職と国家の役職を取り違えないように]
`/town rank add プレイヤー名 assistant` は町長補佐、`/nation rank add プレイヤー名 assistant` は国王補佐です。
同じ `assistant`・`helper`・`treasurer` でも、対象と権限が違います。
どちらの仕事をお願いするのか、相手と確認してから付けましょう。
:::

## 役職を確認する・付ける・外す

### 現在の担当者を見る

```text
/town ranklist
/nation ranklist
```

自分の町・国家の役職と担当者を確認できます。
別の町や国家を見るときは、`/town ranklist 町名`・`/nation ranklist 国家名` と入力します。

### 町の招待担当を任せる例

町長など、`recruiter` を付ける権限のある人が実行します。
`プレイヤー名` は相手のMCIDに置き換えてください。

```text
/town rank add プレイヤー名 recruiter
/town ranklist
```

相手は町への招待を担当できるようになります。
仕事を終えたら、次のコマンドで役職を外せます。

```text
/town rank remove プレイヤー名 recruiter
```

### 国家の外交担当を任せる例

国王など、`diplomat` を付ける権限のある人が実行します。

```text
/nation rank add プレイヤー名 diplomat
/nation ranklist
```

外す場合は `/nation rank remove プレイヤー名 diplomat` です。
付与・解除後は、一覧で担当者が意図したとおりになったか確認しましょう。

## 付けられない・操作できないとき

| 状況 | 確認すること |
| --- | --- |
| 役職を付ける権限がない | 操作する本人に、その役職を付ける権限があるか。町長補佐は町の `vip`・`helper`、国王補佐は国家の `helper` が付与・解除の対象 |
| 相手を指定できない | 町の役職なら同じ町、国家の役職なら同じ国家に所属しているか |
| 役職名が見つからない | 表の英字IDを使っているか。入力中にTab候補も確認する |
| 役職を付けたのに土地を編集できない | 町有地か個人所有地か、どの操作をしようとしているか。`/plot perm` で確認する |
| 役職を外しても操作できる | ほかの役職・土地の許可・別の権限設定で許可されていないか |

判断に迷ったら、MCID・町または国家の名前・役職名・使ったコマンドを町長や運営へ伝えてください。

## 設定と出典

役職の名前と追加権限は、日ノ本鯖の `townyperms.yml` が基準です。
Townyの役職は設定で変えられるため、設定を変更したときはこのページも更新します。
別の権限プラグインによる追加許可や、ほかの保護プラグインの制限がある場合は、その影響も受けます。
