気になる町を見つけたら、まずは町の人に話しかけてみましょう！
住む場所や建築のルールを聞いてから参加すると、暮らしを始めやすくなります

## 町を探して参加する

| コマンド | できること |
| --- | --- |
| `/town list [ページ]` | 町の一覧を見る。2ページ目は`/town list 2` |
| `/town 町名` | 指定した町の情報を見る |
| `/town join 町名` | 自由参加が有効な町に入る。招待制の町には使えません |
| `/invite list [ページ]` | 自分宛ての町の招待を見る |
| `/invite accept 町名` | 指定した町の招待を承諾する |
| `/invite deny 町名` | 指定した町の招待を断る |
| `/invite deny all` | 届いている町の招待をすべて断る |
| `/accept [町名]` | 招待を承諾する短いコマンド。複数届いている場合は町名を指定する |
| `/deny [町名]` | 招待を断る短いコマンド |

`accept`と`deny`は標準の名前です
設定で変更されている場合は、届いた招待のボタンや案内に従ってください
`/invite`または`/invite ?`で、そのサーバーの入力方法を確認できます

例えば`Sakura`という町から招待が届いた場合は、`/invite accept Sakura`で返事をします
すでに別の町に入っていると参加できません
招待が期限切れになっていたら、町の人にもう一度送ってもらいましょう

## 自分と町の情報を見る

| コマンド | できること |
| --- | --- |
| `/resident` | 自分の所属、所有地などの住民情報を見る |
| `/resident プレイヤー名` | 指定した住民の情報を見る |
| `/resident list` | オンラインの住民一覧を見る |
| `/resident tax [プレイヤー名]` | 住民が負担する税金を確認する。経済機能が必要 |
| `/resident plotlist [プレイヤー名] [ページ]` | 所有する土地の一覧を見る。自分の2ページ目は`/resident plotlist 2` |
| `/resident outlawlist [プレイヤー名]` | その住民を無法者に指定している町の一覧を見る |
| `/town` | 自分の町の情報を見る |
| `/town here` | 今立っている場所の町を調べる |
| `/town online [町名]` | 町のオンライン住民を見る |
| `/town reslist [町名]` | オフラインを含む町の住民を見る |
| `/town ranklist [町名]` | 町の役職と担当者を見る |

`/resident`は`/res`、`/town`は`/t`とも書けます
例えば`/res tax`は`/resident tax`と同じ操作です

## 町や自分の拠点へ移動する

| コマンド | 行き先と条件 |
| --- | --- |
| `/town spawn` | 自分の町のスポーンへ移動する |
| `/town spawn 町名` | 指定した町へ移動する。公開設定、所属関係、移動権限などによって制限されます |
| `/town outpost list [ページ]` | 自分の町の前哨地一覧を見る |
| `/town outpost [番号または名前]` | 町の前哨地に移動する。前哨地と移動機能が有効な場合のみ |
| `/resident spawn` | Townyが認識する自分のベッドスポーンへ移動する。ベッドや権限などの条件があります |

移動に料金や待ち時間が設定されていることがあります
案内が出た場合は金額を確認してください
敵対地域からの移動や、移動中の行動が制限されることもあります
日ノ本鯖の`/spawn`や`/home`とは別の機能です

## 自己紹介を書く

```text
/resident set about 建築が好きです！ よろしくお願いします
```

住民情報に自己紹介を表示できます
`/resident set about clear`または`none`で消去、`reset`でサーバーの初期文に戻します
入力できる文字や長さには制限があります

## フレンドを登録する

| コマンド | できること |
| --- | --- |
| `/resident friend add プレイヤー名 [プレイヤー名…]` | 自分のフレンド一覧に追加する |
| `/resident friend remove プレイヤー名 [プレイヤー名…]` | 一覧から外す |
| `/resident friend list` | 登録済みのフレンドを見る |
| `/resident friend list online` | 登録済みのうち、オンラインの人を見る |
| `/resident friend clear` | フレンド登録をすべて解除する。`clearlist`も同じ操作 |

サーバーに住民として登録されている相手なら、オフラインでも名前を指定できます
相手の一覧に自分が自動で登録されるわけではありません

フレンド登録は単なる連絡先ではありません
自分の土地で`friend`に許可している建築や操作を、その人もできるようになります
登録前に[土地の権限](../permissions/)を確認しましょう

古い説明にある`friend add+`・`remove+`は、基準版の処理では受け付けられないため使いません

## 町を抜ける

`/town leave`で自分の町から脱退します
所有地の扱いは土地の種類や設定によって変わるため、家や荷物をどうするか町の人と相談してから実行してください
一般の土地と大使館区画では扱いが異なります

町長は、先に[町長の引き継ぎ](../town-management/#町長を引き継ぐ)が必要です
別の町に入れない原因が「現在の町に所属中」なら、脱退後に改めて招待を受けてください
