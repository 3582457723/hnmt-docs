通貨の単位は「両」です。例えば、1,000両の入金では、コマンドに単位やカンマを付けず`1000`と入力します。

Townyには、個人の所持金とは別に町と国家の銀行があります。
町に寄付したお金は、自分専用の預金ではありません。
用途を確認してから入金しましょう。

経済機能が無効なサーバーでは、このページの一部の操作は使えません。
日ノ本鯖の確定した料金表として数字を掲載しているものではなく、現在の金額はゲーム内で確認してください。

## まず金額を確認する

| コマンド | 確認できるもの |
| --- | --- |
| `/towny prices` | 設立や取得、維持などの設定料金 |
| `/town`・`/nation` | 所属先の銀行、税金などの状態 |
| `/resident tax [プレイヤー名]` | 住民にかかる税金 |
| `/town plots [町名]` | 土地の種類別の集計や税収の目安 |
| `/towny time` | 日次処理までの時間 |
| `/town baltop [町名]` | 町の住民の所持金ランキング |
| `/nation baltop [国家名]` | 国家の住民の所持金ランキング |
| `/town bankhistory [件数]` | 町の銀行取引履歴。参照権限が必要 |
| `/nation bankhistory [件数]` | 国家の銀行取引履歴。参照権限が必要 |

ランキングの公開範囲や、履歴を見られる役職は設定で制限できます。
確認できない場合は、町長・国王に金額や用途を聞いてください。

## 入金と出金

| コマンド | お金の移動先 |
| --- | --- |
| `/town deposit 金額` | 自分の所持金 → 自分の町の銀行 |
| `/town deposit 金額 町名` | 自分の所持金 → 指定した町の銀行。別の町への入金権限が必要な場合あり |
| `/town withdraw 金額` | 町の銀行 → 自分の所持金。町の出金権限と出金許可設定が必要 |
| `/nation deposit 金額` | 自分の所持金 → 自分の国家の銀行 |
| `/nation withdraw 金額` | 国家の銀行 → 自分の所持金。国家の出金権限と出金許可設定が必要 |
| `/nation deposit 金額 町名` | **国家の銀行 → 同じ国家の指定した町の銀行**。国家の資金配分権限が必要 |

:::caution[町名を付けた国家のdepositは、国家からの資金配分です]
`/nation deposit 金額 町名`は個人からの寄付ではなく、国家の銀行から、その国家に所属する町へ資金を移す操作です。
自分のお金を国家へ入れたい場合は、町名を付けずに`/nation deposit 金額`を使ってください。
:::

金額は正の整数で指定します。
例えば`/town deposit 1000`は自分の町へ1,000両を入金する例です。
`金額`の代わりに`all`を指定すると、元の口座から動かせる整数部分の全額が対象になります。
特に出金の`all`は、町や国家の維持費まで動かしてしまわないよう注意してください。

残高不足、出金禁止、上限、経済プラグイン側のエラーなどで失敗することがあります。
成功表示と残高を確認し、処理結果が不明なら履歴を確認してから再実行してください。

## 住民・町が負担する税金

| 税金 | 支払う側 → 受け取る側 |
| --- | --- |
| 住民税 | 町の住民 → 町の銀行 |
| 土地税 | 土地を持つ住民 → 町の銀行。通常・ショップ・大使館で別設定がある |
| 国家税 | 国家に入っている町 → 国家の銀行 |
| 維持費 | 町や国家の銀行から、日次処理などで支払う運営費 |

住民税と土地税は別々にかかることがあります。
割合の税率、上限、免除の役職、支払えない場合の扱いは設定によって変わります。
町の銀行残高が尽きると、破産や町の消滅などに関わるため、設立後も継続して確認しましょう。

## 町長向け：税金と売地の初期価格

| コマンド | 設定するもの |
| --- | --- |
| `/town set taxes 金額または割合` | 住民税の値。固定額か割合かは`taxpercent`の状態で決まる |
| `/town toggle taxpercent [on/off]` | 住民税を割合にするか切り替える |
| `/town set taxpercentcap 金額` | 割合課税の上限額 |
| `/town set plottax 金額` | 通常の個人所有地の土地税 |
| `/town set shoptax 金額` | ショップ区画の土地税 |
| `/town set embassytax 金額` | 大使館区画の土地税 |
| `/town set plotprice 金額` | 通常区画を売り出すときの初期価格 |
| `/town set shopprice 金額` | ショップ区画の初期価格 |
| `/town set embassyprice 金額` | 大使館区画の初期価格 |

土地の初期価格を変えても、すでに売り出した個別区画の価格がすべて自動で希望額になるとは考えず、`/plot perm`と売り出し状態を確認してください。
住民への請求額が変わる設定は、先に町の人へ伝えましょう。

## 国王向け：国家税

| コマンド | 設定するもの |
| --- | --- |
| `/nation set taxes 金額または割合` | 加盟する町への国家税 |
| `/nation toggle taxpercent [on/off]` | 国家税の固定額・割合の切り替え |
| `/nation set taxpercentcap 金額` | 割合課税の上限 |
| `/nation set conqueredtax 金額` | 征服された町に対する税の値。該当機能がある場合のみ |

数値の上限や課税対象はサーバー設定が優先です。
税率を変更したら、町・国家の情報画面で結果を確認してください。
