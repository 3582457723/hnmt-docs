町に入ったら、自分の家を建てる土地を探してみましょう！
町長や案内してくれる人に聞けば、空いている区画を教えてもらえます。

## 土地を買うまで

1. 案内された土地の上に立ちます
2. `/plot perm`で町名、持ち主、売り出し状態や価格を確認します
3. `/resident tax`や町の案内で、その土地にかかる税金も確認します
4. 納得できたら`/plot claim`を実行します
5. 再び`/plot perm`を開き、持ち主が自分になったことを確認します

売り出されていない土地は、通常は購入できません。
町に加入していない場合、一般区画は購入できず、自由参加の町への加入確認が出る場合があります。
町外の人が持てる大使館区画は別扱いです。

## 購入・売却・所有の解除

| コマンド | 意味 |
| --- | --- |
| `/plot claim` | 今いる売り出し中の区画を購入する |
| `/plot claim auto` | 現在地の周囲で取得できる区画を自動選択する。一括購入になるため、最初は単一区画がおすすめ |
| `/plot claim rect 半径` | 四角い範囲の売地をまとめて購入する |
| `/plot claim circle 半径` | 円状の範囲の売地をまとめて購入する |
| `/plot forsale [価格]` | 自分が管理できる区画を売り出す。省略時は町の土地種別ごとの価格を使う |
| `/plot notforsale` | 今いる区画の売り出しを取り消す |
| `/plot unclaim` | 今いる区画の個人所有を手放す。町の領土には残ります |
| `/plot unclaim rect 半径` | 四角い範囲の個人所有を手放す |
| `/plot unclaim circle 半径` | 円状の範囲の個人所有を手放す |

売却の短縮形は`/plot fs`、売却取消は`/plot nfs`です。
例えば`/plot fs 500`は価格500で売り出す入力例です。
**売り出しを取り消しても、その土地を手放すことにはなりません**。

`unclaim`は「購入代金の返金」ではありません。
返金や建築物の保護が続くことを前提にせず、町のルールを確認してから手放してください。

## まとめて売り出す

```text
/plot forsale 500 within rect 1
/plot notforsale rect 1
```

最初の行は周囲の四角い範囲を価格500で売り出す例、次は範囲内の売り出しを取り消す例です。
**売り出すときの範囲指定には`within`が必要**です。
円状なら`rect`を`circle`に置き換えます。
所有者や役職の条件に合わない区画、グループ化された区画などは処理できない場合があります。

半径はブロック数ではなく、Townyの区画を基準に指定します。
サーバーの区画サイズや円・四角の選択方式で範囲が変わるため、[境界表示](../information/#境界と情報表示を切り替える)で位置を確認し、慣れるまでは1区画ずつ操作しましょう。

## 町長が住民の所有を解除する

| コマンド | 意味 |
| --- | --- |
| `/plot evict` | 今いる区画から個人所有者を外す。町の管理権限が必要 |
| `/plot evict forsale` | 所有者を外し、単一区画を再び売り出す |

グループの土地では、所有解除が**グループ全体**に及びます。
基準版ではグループに対する`forsale`の再販売指定は単一区画と同じ処理ではないため、解除後に`/plot group forsale 価格`で売り出し状態を確認・設定してください。

## 買えない・建築できないとき

| 表示や状況 | 確認すること |
| --- | --- |
| 売地が見つからない | その場所が売り出し中か、正しい区画に立っているか |
| お金が足りない | 購入価格。複数区画やグループは合計額も確認 |
| 所有上限に達した | `/resident plotlist`で現在の所有地を確認 |
| 町に参加してからの日数が条件を満たさない | 初心者向けなどの購入条件があるか、町の人に確認 |
| 買ったのに操作できない | `/plot perm`で所有者を確認し、[権限](../permissions/)と町のルールを確認 |
| グループの案内が出た | [グループの売買](../land-settings/#区画をグループにまとめる)を確認 |

購入だけでは、町の建築ルールや別プラグインの保護を無効にできません。
分からない場合は、区画の場所と表示されたエラーを町の人に伝えてみましょう。
