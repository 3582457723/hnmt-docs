町長・町の役職が使う操作のページです。
同じ役職名でも権限はサーバー設定で変わります。
「町長向け」と書かれている操作が、担当の役職にも許可される場合があります。

## 住民を招待する

| コマンド | できること |
| --- | --- |
| `/town add プレイヤー名 [プレイヤー名…]` | 町に招待する |
| `/town invite プレイヤー名` | 町に招待する別の入力方法 |
| `/town add -プレイヤー名` | 指定した相手への招待を取り消す |
| `/town invite sent` | 町から送った招待を確認する |
| `/town invite sent removeall` | 町から送った招待をすべて取り消す |
| `/town invite received [ページ]` | 町に届いた国家からの招待を確認する |
| `/town invite accept 国家名` | 国家への加入招待を承諾する |
| `/town invite deny 国家名` | 国家への加入招待を断る |
| `/town kick プレイヤー名 [プレイヤー名…]` | 住民を町から外す |
| `/town toggle open [on/off]` | 招待なしで参加できる町にする・戻す |

`/town invite`だけなら招待のヘルプを表示します。
招待された側は[参加の手順](../residents/)に沿って返事をします。
人数上限、招待拒否、既存の所属などで送れない・加入できない場合があります。

自由参加を有効にしても、全区画で誰でも建築できるようにはなりません。
町の案内、売地、[権限](../permissions/)も別に整えましょう。

## 役職と連絡

| コマンド | できること |
| --- | --- |
| `/town ranklist [町名]` | 役職と担当者を見る |
| `/town rank add プレイヤー名 役職名` | 町の住民に役職を付ける |
| `/town rank remove プレイヤー名 役職名` | 役職を外す |
| `/town say メッセージ` | 町の住民へ町の告知を送る |
| `/town mayor ?` | 町長向けのヘルプを表示する |
| `/town purge 日数` | 指定日数以上の非活動住民をまとめて外すための確認を開始する |

役職ごとの担当と注意点は[ランク・役職](../ranks/)で案内しています。
`builder`・`recruiter`・`treasurer`など、お願いしたい仕事に合う役職を選びましょう。

:::caution[役職を付ける前に、任せる操作を確認しましょう]
役職には出金・領土解除・住民管理など、町全体に影響する権限が含まれる場合があります。
同じ役職名でも、できる操作はサーバー設定によって変わります。
任せる内容を確認し、信頼できる住民にだけ付けてください。建築を手伝ってもらうだけなら、土地の許可で対応できます。
:::

`/town purge 30`は「30日以上活動していない対象者を確認する」入力例です。
表示された対象者の一覧を確認し、意図した人だけか確かめてから承諾します。

## 町長を引き継ぐ

`/town set mayor プレイヤー名`で町長を引き継ぎます。
引き継ぐ相手が町に所属していることを確認し、町の資金や運営方針も先に共有してください。
自分の役職・権限も変わるため、引き継ぎ後に`/town`で新しい町長を確認しましょう。

## 名前と案内を整える

| コマンド | できること |
| --- | --- |
| `/town set name 新しい町名` | 町名を変更する。使える文字・重複・変更費用などの条件あり |
| `/town set board メッセージ` | 町の案内文を設定する |
| `/town set board none` | 案内文を消去する。`reset`は初期値に戻す |
| `/town set tag 短縮名` | チャットなどに使う町の短縮名を設定する。文字数は設定による |
| `/town set tag clear` | 短縮名を外す |
| `/town set title プレイヤー名 [文字列]` | 住民の名前の前に付く肩書を設定する。文字列省略で消去 |
| `/town set surname プレイヤー名 [文字列]` | 名前の後ろに付く肩書を設定する。文字列省略で消去 |
| `/town set mapcolor 色名` | 連携地図などで使う町の色を設定する。使える色はTabで確認 |

例えば`/town set board 初めての方は町長に声をかけてください！`で入口の案内を用意できます。
町名や肩書は、別プラグインのチャット形式によって表示されない場合もあります。

## PvP・環境の設定

次の書式で使います：`/town toggle 設定名 [on/off]`。
省略すると現在の状態が反転します。
意図しない反転を避けるなら、`/town toggle pvp off`のように指定しましょう。

| 設定名 | 変わること |
| --- | --- |
| `pvp` | 町のPvP設定。ワールドの強制設定、アリーナ、待ち時間などが優先されることあり |
| `fire` | 町の火の扱い |
| `explosion` | 町の爆発の扱い |
| `mobs` | 町のモブ出現の扱い |
| `public` | 町スポーンの公開状態 |
| `open` | 招待なしの参加受付 |
| `taxpercent` | 住民税の固定額・割合の切り替え |
| `nationzone` | 国家周辺の保護領域の扱い。国家ゾーン機能が有効な場合 |
| `neutral`・`peaceful` | 中立状態の切り替え。同じ用途の別名で、利用条件や費用は設定による |

変更が拒否されたら、権限・町の状態・近くのプレイヤー・待ち時間など、表示された理由を確認してください。
Towny以外の戦争プラグインのルールまで、この設定だけで変更できるわけではありません。

## 無法者の指定

| コマンド | できること |
| --- | --- |
| `/town outlaw add プレイヤー名` | 町の無法者に指定する |
| `/town outlaw remove プレイヤー名` | 指定を解除する |
| `/town outlawlist [町名]` | 指定されている住民を見る |

`/town ban add`・`/town ban remove`は同じ操作の別名です。
これはサーバー全体から追放するBANではありません。
町への加入、侵入時の処理、投獄などに関わり、効果は設定によって変わります。

税金・価格の変更は[銀行・税金・維持費](../economy/)、領土は[町の設立と領土](../town-land/)、牢屋は[牢屋と保釈](../jails/)を参照してください
