「友達と家を建てたい」「見学はできても壊せないようにしたい」など、土地ごとにできる操作を決められます。
まずは今いる区画で`/plot perm`を使い、持ち主と設定を確認しましょう。

## どの土地を変更するか

| コマンドの先頭 | 変更する範囲 |
| --- | --- |
| `/plot set perm` | 今立っている区画。グループの一部ならグループ用コマンドの案内に従う |
| `/plot group set perm` | 今いる区画のグループ全体 |
| `/resident set perm` | 自分の所有地の権限をまとめて管理する設定。1区画だけの操作ではありません |
| `/town set perm` | 町の権限設定。町有地や設定を継承する土地に関係し、個別に変更済みの土地とは区別されます |

町や自分の設定をまとめて変更するときは、ほかの土地も含まれることを確認してください

## 誰に、何を許可するか

| 対象 | 意味 |
| --- | --- |
| `friend` | 個人所有地で、持ち主がフレンド登録している住民 |
| `resident` | 町有地では、その町の住民。個人所有地のフレンド枠とは区別する |
| `town` | 個人所有地では、持ち主と同じ町の住民 |
| `nation` | 町有地では、同じ国家の住民 |
| `ally` | 同盟国に属する住民 |
| `outsider` | 上の関係に当てはまらない外部の住民 |

対象は土地の所有形態によって意味が変わります。
町有地は`resident / nation / ally / outsider`、個人所有地は`friend / town / ally / outsider`を使います。
`nation`や同盟の扱いも含め、最終的には`/plot perm`に表示される関係と状態を確認しましょう。

| 操作 | 意味 |
| --- | --- |
| `build` | ブロックを置く |
| `destroy` | ブロックを壊す |
| `switch` | ドア、ボタン、チェストなど、設定対象のブロックを操作する |
| `itemuse` | バケツなど、設定対象のアイテムを使う |

チェストの保護や特別なブロックの扱いは、ほかのプラグインやサーバー設定も影響します。
「switchを許可すればすべての操作が必ずできる」という意味ではありません。

## 入力の形と具体例

| 入力の形 | 変更内容 |
| --- | --- |
| `/plot set perm 対象 操作 on` | 対象と操作をひとつずつ指定して許可する |
| `/plot set perm 対象 操作 off` | 指定した組み合わせを禁止する |
| `/plot set perm 対象 on` | その対象に複数の操作をまとめて許可する |
| `/plot set perm 操作 off` | その操作を各対象でまとめて禁止する |
| `/plot set perm off` | 広い範囲の操作権限をまとめて禁止する |
| `/plot set perm reset` | 個人所有地は所有者、町有地は町の設定に戻す |

例えば、自分の家でフレンドにブロックの設置と破壊だけを許可するなら、次の順で設定します

```text
/resident friend add プレイヤー名
/plot set perm friend build on
/plot set perm friend destroy on
/plot perm
```

`プレイヤー名`は一緒に遊ぶ相手のMCID（Minecraftのプレイヤー名）に置き換えてください。
別の土地でもフレンド向け設定が使われるため、その範囲も確認しましょう。
相手にすべてを許可したくない場合は、次の個別設定が使えます。

上の書式は`/resident set perm`・`/town set perm`・`/plot group set perm`でも対象範囲を変えて使えます。
`/resident set perm reset`や`/town set perm reset`は、配下の土地へ権限を揃える操作にもなるため、個別設定を残したい土地がないか先に確認してください。

## 特定の人だけ設定する

| コマンド | できること |
| --- | --- |
| `/plot perm gui` | 今いる区画の権限GUIを開く |
| `/plot perm add プレイヤー名` | その人向けの個別設定を追加する。追加後はGUIで内容を確認・調整する |
| `/plot perm remove プレイヤー名` | その人の個別設定を削除する |
| `/plot group perm gui` | グループの権限GUIを開く |
| `/plot group perm add プレイヤー名` | グループに個別設定を追加する |
| `/plot group perm remove プレイヤー名` | グループから個別設定を削除する |

個別設定は一般の関係別設定に対する例外です。
解除後は通常の関係別設定が適用されるので、「remove＝全操作を必ず禁止」ではありません。

## trustで広く許可する

| コマンド | 変更範囲 |
| --- | --- |
| `/plot trust add プレイヤー名` | 今いる区画で、その人を信頼する |
| `/plot trust remove プレイヤー名` | 区画の信頼登録を外す |
| `/plot group trust add プレイヤー名` | グループ全体で信頼する |
| `/plot group trust remove プレイヤー名` | グループの信頼登録を外す |
| `/town trust add プレイヤー名` | 町の信頼登録に追加する。町の管理権限が必要 |
| `/town trust remove プレイヤー名` | 町の信頼登録を外す |
| `/town trust list` | 町の信頼登録を見る |
| `/town trusttown add 町名` | 指定した町を町単位で信頼する |
| `/town trusttown remove 町名` | 町単位の信頼登録を外す |
| `/town trusttown list` | 信頼している町を見る |
| `/town plots 町名 trustlist [プレイヤー名] [ページ]` | 町内の区画の信頼登録を調べる |

`trust`は建築などの広い許可につながります。
チェストの使用だけなど、限定したいときは関係別・個別設定を使いましょう。
町のtrustは町有地を含む管理範囲に関係し、ほかの住民の土地を自由に扱うための町長権限を与えるコマンドではありません。

## 設定しても使えない場合

現在地が自分の土地か、グループの土地か、荒野かを確認してください。
町・ワールド側で強制されるPvPなどの状態や、別の保護プラグインは、このコマンドだけでは解除できません。
所有者の画面と、操作できない人のMCID・操作・場所を一緒に町長へ伝えると調べやすくなります。
