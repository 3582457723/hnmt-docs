家だけでなく、商店街や宿屋、畑など、町の使い方に合わせて土地を整理できます
区画種別の変更には所有者・町の役職の権限が必要で、費用がかかることもあります

## 土地の種類を変える

対象の区画に立ち、`/plot set 種類`を実行します
例えば`/plot set shop`でショップ区画へ変更します

| 種類 | 用途と注意点 |
| --- | --- |
| `reset` | 通常区画へ戻す。建物を更地にするコマンドではない |
| `shop` | お店向けの区画。ショップ用の土地税・価格が使われる |
| `embassy` | 町外の住民も所有できる大使館区画。通常の所属条件と異なる |
| `arena` | PvP向けの区画。通常の土地と戦闘・フレンド保護などの扱いが変わる |
| `wilds` | 設定対象の自然ブロックなどを利用させる区画。対象は`/towny wildsblocks`で確認 |
| `inn` | 外部の住民のベッド利用に関わる宿屋区画。リスポーンの設定条件あり |
| `jail` | 牢屋の区画と移動先を設定する。[牢屋の説明](../jails/)を確認 |
| `farm` | 農業向けの区画。対象ブロック・操作は設定による |
| `bank` | 銀行利用を制限する設定で使う区画。経済・銀行の設定が必要 |
| `outpost` | 前哨地の扱いを設定する。新しい荒野を取得するなら`/town claim outpost`を使う |

`shop`にしてもQuickShopのお店が自動でできるわけではありません
チェストショップの作成は[お店のガイド](../../town/shops/)を参照してください
区画種別はサーバーで追加・制限できるため、使える候補はTabと`/plot set ?`でも確認できます

| コマンド | できること |
| --- | --- |
| `/plot set name 名前` | 区画に名前を付ける |
| `/plot set outpost spawn` | 前哨地のスポーンを現在地に置くための指定 |
| `/plot set minjoindays 日数` | 土地を買う住民の、町への最低所属日数を指定する |
| `/plot set maxjoindays 日数` | 土地を買う住民の、町への最大所属日数を指定する |
| `/plot set minjoindays clear` | 最低日数の条件を外す |
| `/plot set maxjoindays clear` | 最大日数の条件を外す |

例えば最大日数を設定すると、加入したばかりの人向けの売地を用意できます
区画の売り出しや価格の設定は別に必要です

## 区画のPvP・環境を変える

書式は`/plot toggle 設定名 [on/off]`です

| 設定名 | 変わること |
| --- | --- |
| `pvp` | その区画のPvP |
| `fire` | 火の扱い |
| `explosion` | 爆発の扱い |
| `mobs` | モブ出現の扱い |
| `taxed` | 区画の課税状態。土地税を免除する管理権限が必要 |

例：`/plot toggle pvp off`
町やワールドの強制設定、アリーナなどの土地種別が優先される場合があります
`/resident toggle pvp`・`fire`・`explosion`・`mobs`は、**自分の所有地側の設定**を変更する操作です
自分のキャラクターだけを無敵にする設定ではありません

## 区画をグループにまとめる

隣接する複数区画を、一軒の大きな家のようにまとめて扱う機能です
同じ町・種類などの条件を満たす土地で使います
最初の区画で`/plot group add 名前`を実行し、追加したい別の区画でも同じ名前を指定します

| コマンド | できること |
| --- | --- |
| `/plot group` | グループのヘルプと、現在地の所属情報を見る |
| `/plot group add 名前` | 今いる区画をグループに追加する。存在しなければ作成する。`new`・`create`も同じ用途 |
| `/plot group remove` | 今いる区画をグループから外す |
| `/plot group delete` | 現在地のグループを解散する。土地自体の削除ではない |
| `/plot group rename 新しい名前` | グループ名を変更する |
| `/plot group forsale 価格` | グループをひとまとめに売り出す。`fs`も同じ |
| `/plot group notforsale` | グループの売り出しを取り消す。`nfs`も同じ |
| `/plot group set 種類` | グループの種類を変える。`jail`への一括変更はできない |
| `/plot group set minjoindays 日数` | グループの購入条件を設定する |
| `/plot group set maxjoindays 日数` | グループの購入条件を設定する |
| `/plot group toggle 設定名 [on/off]` | `pvp`・`fire`・`explosion`・`mobs`・`taxed`をグループで変更する |
| `/plot group set perm …` | [関係・操作別の権限](../permissions/)をグループに設定する |
| `/plot group perm gui` | グループの個別権限GUIを開く |
| `/plot group perm add プレイヤー名` | 個別権限の対象を追加する |
| `/plot group perm remove プレイヤー名` | 個別権限を解除する |
| `/plot group trust add プレイヤー名` | グループで信頼する相手を追加する |
| `/plot group trust remove プレイヤー名` | 信頼登録を解除する |

グループの売地を`/plot claim`で買うと、区画ひとつではなくグループ全体の購入になります
売却・追い出し・設定変更の前に、グループ名と区画数を確認しましょう

基準版ではグループの最大所属日数が意図どおりに反映されないため、購入の日数条件は**単一区画の`/plot set minjoindays`・`maxjoindays`で設定し、結果を確認**してください
最新版へ更新した場合は修正状況を確認してから使い分けてください

## 町を地区に分ける

地区は「住宅地」「商店街」など、町の区画を分類する仕組みです
グループの一括所有・一括売買とは別なので、地区を作っただけでは持ち主や価格は変わりません

| コマンド | できること |
| --- | --- |
| `/plot district add 名前` | 現在地を地区へ追加する。なければ作成する |
| `/plot district new 名前` | 地区を作成・追加する別名。`create`も同じ |
| `/plot district remove` | 現在地を地区から外す |
| `/plot district rename 新しい名前` | 現在地の地区を改名する |
| `/plot district delete` | 現在地の地区を解散する |

作業モードの`plotgroup`・`district`を使う場合は、[モードの説明](../information/#作業しながら土地を管理するモード)を先に読んでください

## 設定対象のブロックを片付ける

`/plot clear`は、設定された種類のブロックを区画から除去する操作です
すべての建物を安全に初期化したり、削除したものを復元したりするコマンドではありません
先に`/towny plotclearblocks`で対象を確認し、権限のある土地でのみ使ってください
