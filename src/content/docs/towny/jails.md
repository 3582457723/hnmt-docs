牢屋はTownyの投獄機能です
有効かどうか、投獄の条件、時間、保釈金はサーバー設定によって変わります
サーバールール上の処罰・BANとは別の仕組みです

## 投獄されたとき

`/resident jail`で保釈に関する案内を確認できます
保釈機能が有効で、支払える残高がある場合は`/resident jail paybail`で保釈金を支払います
金額と案内を確認してから実行してください

解除できない場合は、表示された理由と自分のMCIDを町長・運営に伝えましょう
通常のホームやスポーンへの移動では、投獄状態を解除できるとは限りません

## 町長・担当役職向け：牢屋を用意する

1. 自分の町の管理できる区画に、床と頭上の空間がある安全な場所を用意します
2. 牢屋の移動先に立ち、`/plot set jail`を実行します
3. `/town jail list`で登録結果を確認します
4. 必要なら独房の追加や、主に使う牢屋の指定を行います

| コマンド | できること |
| --- | --- |
| `/plot set jail` | 今いる区画を牢屋にする。位置設定も関係するため、安全な場所に立って使う |
| `/plot jailcell add` | 現在地を、その牢屋の独房の移動先として追加する |
| `/plot jailcell remove` | 現在地と一致する独房の移動先を削除する。最後の1室は削除できない |
| `/town set primaryjail` | 今いる牢屋を町の主な牢屋に指定する |
| `/town jail list [ページ]` | 町の牢屋を確認する |
| `/plot set reset` | 牢屋区画を通常区画へ戻す。収監者などの状態を確認してから行う |

## 投獄と解放

`/town jail`だけを入力すると、そのサーバーでの書式を確認できます
**保釈機能の有効・無効で引数の位置が変わります**

保釈あり：

```text
/town jail プレイヤー名 [時間] [保釈金] [牢屋番号] [独房番号]
```

保釈なし：

```text
/town jail プレイヤー名 [時間] [牢屋番号] [独房番号]
```

時間は時間単位です
例えば`/town jail プレイヤー名 1`は1時間の指定例です
自分の町の住民であること、オンラインであること、初心者保護期間を過ぎていること、町の手数料を払えることなどが条件になります

`/town unjail プレイヤー名`で投獄を解除します
無法者の指定や戦闘時の自動投獄は、上の手動投獄とは別の条件で動きます
使えるからといって自由に投獄してよいわけではなく、町とサーバーのルールに従ってください
