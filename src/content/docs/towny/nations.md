国家は複数の町が集まる仕組みです。
住民個人が町を抜けて入るのではなく、**町が国家に参加**します。
まずは自分の町長と相談してみましょう！

## 国家を調べる・移動する

| コマンド | できること |
| --- | --- |
| `/nation` | 自分の国家の情報を見る |
| `/nation 国家名` | 指定した国家の情報を見る |
| `/nation list [ページ]` | 国家の一覧を見る。並べ替えは[一覧の説明](../information/#町国家一覧を並べ替える)へ |
| `/nation online [国家名]` | オンラインの国家住民を見る |
| `/nation townlist [国家名]` | 加盟している町を見る |
| `/nation ranklist [国家名]` | 国家の役職と担当者を見る |
| `/nation allylist [国家名]` | 同盟国を見る |
| `/nation enemylist [国家名]` | 敵対国を見る |
| `/nation spawn [国家名]` | 国家スポーンへ移動する。公開状態・所属・権限・料金などの条件あり |
| `/nation townoutposts` | 前哨地移動の入力例を確認する。移動するには町名と番号が必要 |
| `/nation townoutposts listall` | 国家内の前哨地をまとめて一覧表示する |
| `/nation townoutposts 町名 list` | 指定した町の前哨地を一覧で見る |
| `/nation townoutposts 町名 番号` | 指定した町の前哨地へ移動する。利用条件あり |

`/nation`は`/n`・`/nat`にも省略できます。
`townoutposts`は`outpost`とも書けます。
国家へ所属しても、ほかの町の土地で自由に建築できるとは限りません。

## 町長向け：国家に参加する・抜ける

| コマンド | できること |
| --- | --- |
| `/nation join 国家名` | 自由参加の国家へ自分の町を加入させる |
| `/town invite received` | 自分の町に届いた国家の招待を確認する |
| `/town invite accept 国家名` | 国家への招待を承諾する |
| `/town invite deny 国家名` | 国家への招待を断る |
| `/nation leave` | 自分の町を国家から脱退させる |

加入には、最低住民数、首都からの距離、国家の町数上限、制裁指定などの条件があります。
国家税や同盟・敵対関係も確認してから加入しましょう。
首都の町が脱退する場合は、先に首都の引き継ぎが必要になることがあります。

## 国家をつくる

町長が`/nation new 国家名`で設立します。
`/nation create 国家名`も同じ操作です。
設立費用や必要な町の規模などを`/towny prices`とサーバーの案内で確認してください。
設立後は`/nation`で国王・首都・銀行を確認し、維持費のための資金を入れましょう。

## 国王・国家の役職向け：加盟する町の管理

| コマンド | できること |
| --- | --- |
| `/nation add 町名 [町名…]` | 町に国家加入の招待を送る |
| `/nation invite 町名` | 町を招待する別の入力方法 |
| `/nation invite -町名` | 指定した町への招待を取り消す。`/nation add -町名`も同じ |
| `/nation invite sent [ページ]` | 送った招待を確認する |
| `/nation kick 町名 [町名…]` | 指定した町を国家から外す |
| `/nation toggle open [on/off]` | 町長が招待なしで加入できる状態を切り替える |
| `/nation rank add プレイヤー名 役職名` | 国家の住民に役職を付ける |
| `/nation rank remove プレイヤー名 役職名` | 国家の役職を外す |
| `/nation say メッセージ` | 国家の住民へ告知を送る |
| `/nation king ?` | 国王向けヘルプを見る。`/nation leader ?`も同じ |

国家の役職は町の役職と別です。
国家の`diplomat`・`treasurer`・`coking`など、役職ごとの権限は[ランク・役職](../ranks/#国家の役職)で確認できます。

## 名前・首都・案内の設定

| コマンド | できること |
| --- | --- |
| `/nation set name 新しい国家名` | 国家名を変更する |
| `/nation set king プレイヤー名` | 国王を引き継ぐ。`set leader`も同じ用途 |
| `/nation set capital 町名` | 首都を変更する。加盟する町などの条件あり |
| `/nation set board メッセージ` | 国家の案内文を設定する |
| `/nation set board none` | 案内文を消去する。`reset`は初期値に戻す |
| `/nation set tag 短縮名` | 国家の短縮名を設定する |
| `/nation set tag clear` | 短縮名を消去する |
| `/nation set title プレイヤー名 [文字列]` | 住民の名前の前に付く肩書を設定する。文字列省略で消去 |
| `/nation set surname プレイヤー名 [文字列]` | 名前の後ろに付く肩書を設定する。文字列省略で消去 |
| `/nation set mapcolor 色名` | 連携地図などで使う色を設定する。色名はTabで確認 |
| `/nation set spawn` | 現在地を国家スポーンにする。首都内などの条件あり |
| `/nation set spawncost 金額` | 国家スポーンへの移動料金を設定する |
| `/nation toggle public [on/off]` | 国家スポーンの公開状態を切り替える |
| `/nation toggle neutral [on/off]` | 中立状態を切り替える。`peaceful`も同じ用途 |

国王の引き継ぎは、その人の町や首都との関係にも影響します。
必要な所属・役職条件を満たす相手と相談してから実行してください。
中立機能は費用や別プラグインの制限がある場合もあります。

## 国家を合併する・削除する

`/nation merge 相手の国家名`は、**自分の国家を残し、相手の国家を統合する**申請です。
相手の国王の確認が必要です。

:::caution[国家の合併では、加盟する町にも影響があります]
例えば自分の国家が`Asahi`のときに`/nation merge Akatsuki`を実行すると、相手の承諾後に残るのは`Asahi`です。
相手の国家の銀行残高や加盟する町が、残る国家へまとめられます。

首都からの距離制限によって、合併後の国家に残れない町が出る場合があります。
対象の町が表示されたら、承諾する前に各町長と相談してください。

残る国家の首都・国家税・同盟や敵対関係と、合併後の役職も確認しましょう。
合併を取り消す通常コマンドはありません。国王同士だけで進めず、加盟する町にも説明してから実行してください。
:::

:::caution[国家からの脱退と、国家の削除を取り違えないでください]
`/nation delete`は自分の国家を削除する操作です。
国家の銀行や所属関係に影響します。
町を国家から抜けさせたいだけなら、町長向けの`/nation leave`と混同しないでください。
:::

入出金・税金は[銀行・税金・維持費](../economy/)、同盟と敵対は[国家の外交](../diplomacy/)で詳しく説明しています
