今日の運勢は何でしょう？
遊びに来たら、おみくじで1日の運試しをしてみましょう！

おみくじは**無料で1日1回**引けます。
運勢が決まると、その結果に応じた通貨を受け取れます。

## おみくじを引く

チャットで、次のコマンドを実行します。

```text
/omikuji
```

1. おみくじの画面が開きます。
2. 中央にある「**おみくじ筒**」をクリックします。
3. 周りのガラス板の色が入れ替わる演出を待ちます。
4. 中央の紙に表示された運勢と報酬を確認します。

結果はチャットと画面中央のタイトルでも確認できます。
運勢に合わせて、画面の色や通知音も変わります！

:::tip[参加後の案内からも開けます]
まだ今日のおみくじを引いていないときは、参加して少しするとチャットに案内が届きます。
［**おみくじを引く**］を押しても、同じ画面を開けます。
案内を見逃した場合は、`/omikuji`を入力してください。
:::

## 運勢と報酬

運勢は次の6種類です。
初期設定では、凶でも通貨を受け取れます。

| 運勢 | 確率（初期値） | 報酬（初期値） |
| --- | --- | --- |
| 大吉 | 3% | 3,000 |
| 中吉 | 10% | 1,500 |
| 吉 | 27% | 800 |
| 小吉 | 27% | 500 |
| 末吉 | 23% | 300 |
| 凶 | 10% | 100 |

確率と報酬はサーバー設定によって変わります。
実際に受け取った金額は、画面やチャットの案内を確認してください。
報酬は通貨として入金され、アイテムとして受け取るものではありません。

大吉が出た場合は、設定が有効ならほかのプレイヤーにもお知らせが流れます。
うれしい結果が出たら、みんなでお祝いできるといいですね！

## 次はいつ引ける？

**毎日、日本時間（JST）の午前0時**に日付が切り替わります。
前に引いた時刻から24時間待つ仕組みではありません。

例えば、23時50分に引いた場合は、その10分後の午前0時から次の日のおみくじを引けます。

同じ日にもう一度`/omikuji`を開くと、その日の結果を確認できます。
新しい抽選や、同じ報酬の再入金は行われません。
退出して入り直しても、その日に引いた記録は残ります。

## 途中で画面を閉じたとき

**画面を閉じても、確定した運勢や入金は取り消されません。**
演出の途中で閉じた場合も、入金済みの報酬は有効で、オンラインなら結果をチャットで確認できます。

:::note[連打せず、結果を待ちましょう]
何度クリックしても、同じ日に抽選や入金が繰り返されることはありません。
「おみくじを引いています」と表示されたら、そのまま少し待ってください。
:::

## 引けない・報酬が分からないとき

| 表示・状況 | 確認すること |
| --- | --- |
| 今日はもう引いている | 今日の結果を確認し、次の日の午前0時以降に引く |
| 現在お休み中 | 利用できるようになるまで待つ |
| 権限がない | 運営に利用できるか確認する |
| 経済の準備ができていない | 少し待ってから、もう一度試す |
| 記録を保存できない・入金できない | 表示された案内に従って、もう一度試す |
| 入金を確認できない | 残高を確認し、報酬が反映されていなければ運営へ連絡する |

:::caution[「入金を確認できない」と出たら]
この場合は、通常の入金失敗と対応が異なります。
重複した入金を防ぐため、その日の抽選記録が残る場合があります。
引き直そうと繰り返さず、残高と表示されたメッセージを確認してください。
報酬が反映されていないときは、実行したおおよその時刻と一緒に運営へ伝えましょう。
:::

繰り返し失敗する場合も、チャットの案内を控えて相談してください。
