友達の建築を見に行ったり、一緒に冒険へ出かけたり！
テレポート申請を使うと、相手の承認を受けて合流できます。

**自分が相手のところへ行くか、相手をこちらへ呼ぶか**で、使うコマンドが変わります。

## 行く・呼ぶを選ぶ

| コマンド | 移動の向き |
| --- | --- |
| `/tpa` | 自分 → 相手のところ |
| `/tpahere` | 相手 → 自分のところ |

どちらも、コマンドの後ろに相手のMCIDを付けて実行します。
名前はTabキーで補完できるので、途中まで入力して候補から選べます。
相手もオンラインのときに使ってください。

:::caution[呼び出し申請では、承認した人が移動します]
`/tpahere`の申請が届いたら、自分が相手のところへ移動することになります。
申請者の名前と移動の向きを確認してから、承認しましょう。
:::

## 相手のところへ行く

例えば、`Alex`さんのところへ行く場合は、次のコマンドを実行します。

```text
/tpa Alex
```

1. 申請を送り、相手が承認するのを待ちます。
2. 承認されたら、カウントダウンが始まります。
3. その場で待つと、相手のところへ移動します。

初期設定では、承認されてから**5秒後**に移動します。
待機中は残り時間と通知音が出るので、移動完了まで待ちましょう！

## 相手をこちらへ呼ぶ

相手を呼びたい場所で、安全な足場を確保してから申請します。

```text
/tpahere Alex
```

`Alex`さんが承認すると、**Alexさん側**でカウントダウンが始まります。
終わるとAlexさんがこちらへ移動します。

:::tip[合流する場所で待っていましょう]
移動先は、待機終了時にいる相手の位置です。
呼ぶ側も、足場のある落ち着ける場所で待っていると合流しやすいです！
読み込み中に移動先の人が動くと、中止される場合があります。
:::

## 届いた申請に返事をする

チャットに、申請者・移動の向き・有効期限と、<strong>［✔ 承認する］［✕ 拒否する］</strong>が表示されます。
内容を確認して、どちらかのボタンを押してください。

コマンドでも返事ができます。

| コマンド | 操作 |
| --- | --- |
| `/tpaccept` | 届いている申請を承認する |
| `/tpdeny` | 届いている申請を拒否する |

### 複数の申請が届いているとき

返事をしたい申請のボタンを押すか、コマンドに申請者の名前を付けます。

```text
/tpaccept Alex
/tpdeny Alex
```

<strong>両方を入力する必要はありません。</strong>承認か拒否のどちらかを選んでください。
名前を付けずに実行しても、複数の中から勝手に選んで承認されることはありません。

古い申請や期限切れのボタンは使えません。
同じ人から新しい申請が来た場合も、新しい申請のボタンで返事をしてください。

## 申請・移動を取り消す

自分が送った申請を取り消す場合は、次のコマンドを実行します。

```text
/tpcancel
```

申請した人は、承認後の移動待機も取り消せます。
**受け取った申請を断る操作は、承認前に`/tpdeny`で行います。**

初期設定では、実際に移動する人が待機中に歩くか、ダメージを受けると移動が中止されます。
視点を動かすだけでは取り消されません。

:::note[呼び出される側が、承認後にやめたいとき]
`/tpahere`を受け取った人は申請者ではないため、`/tpcancel`でその申請を取り消すことはできません。
初期設定では、移動する本人がその場から歩くと中止できます。
:::

## 期限と待ち時間

| 項目 | 初期設定 | いつから数えるか |
| --- | --- | --- |
| 申請の有効期限 | 120秒（2分） | 申請を送ったときから、承認を待つ間 |
| 移動までの待機 | 5秒 | 相手が承認したときから |
| 次の申請までの間隔 | 10秒 | 前の申請を送ったときから |

これらの時間や、移動・ダメージによる取消条件はサーバー設定で変わります。
実際に表示された残り時間や案内を確認してください。

申請は1人1件ずつ送れます。
送り直すときは、今の申請を取り消すか、返事・期限切れを待ちましょう。
取り消しても再申請の待ち時間は省略されません。

## 移動できないとき

| 表示・状況 | 確認すること |
| --- | --- |
| プレイヤーが見つからない | MCIDと、相手がオンラインかを確認する |
| 自分に申請できない | 移動したい相手のMCIDを入力する |
| 申請・移動の処理中 | 自分の申請を取り消すか、進行中の処理が終わるまで待つ |
| 相手とテレポートできない | 両者が通常の状態か、権限や無視設定が関係していないか確認する |
| 申請が見つからない・期限切れ | 必要なら相手に新しい申請を送ってもらう |
| 安全な足場がない・ボーダー外 | 合流先の人が、ボーダー内の安全な足場へ移動してから申請し直す |
| 読み込みが間に合わない | 自動では再試行されないので、少し待ってから申請し直す |

乗り物に乗っているときや、同乗者がいるとき、死亡中には使えません。
どちらかが退出した場合も申請・待機は取り消され、入り直しても再開されません。

[無視設定](../messages/)は双方向に適用されます。
どちらかが相手を無視している場合は、申請や移動ができません。

繰り返し失敗するときは、表示されたメッセージ・実行した時刻・双方の場所を控えて運営に相談してください。
