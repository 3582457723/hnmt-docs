チャット欄を開いて入力してください  
`プレイヤー名` や `名前` の部分は、使いたい相手やホームの名前に置き換えます

スマホで表が画面に収まらないときは、表を左右に動かして確認できます

| コマンド | できること |
| --- | --- |
| `/home` | ホームの管理画面を開く |
| `/home 名前` | 指定したホームに移動する |
| `/sethome 名前` | 今いる場所をホームに登録する |
| `/spawn` | 共通スポーンに戻る |
| `/tpa プレイヤー名` | 相手のところへ移動する申請を送る |
| `/tpahere プレイヤー名` | 相手をこちらへ呼ぶ申請を送る |
| `/tpaccept`・`/tpaccept プレイヤー名` | 届いた申請を承認する |
| `/tpdeny`・`/tpdeny プレイヤー名` | 届いた申請を拒否する |
| `/tpcancel` | 自分が送った申請・移動待機を取り消す |
| `/msg プレイヤー名 本文` | 個別メッセージを送る |
| `/reply 本文` | 個別メッセージに返信する |
| `/ignore プレイヤー名` | 無視設定を登録・解除する |
| `/ignore list` | 無視設定の一覧を見る |
| `/tips on` | Tipsの自動表示を再開する |
| `/tips off` | Tipsの自動表示を止める |
| `/tips reset` | 個別に隠したTipsを戻す |
| `/omikuji` | 1日1回のおみくじを引く・今日の結果を見る |

毎日の運試しは[おみくじの案内](../omikuji/)をご覧ください。

合流するときの操作や、移動する人の違いは[テレポート申請の案内](../tpa/)をご覧ください。

町やお店の操作は、[町への参加と住民の操作](../../towny/residents/)・[お店で取引する](../../town/shops/)をご覧ください。
お店のコマンドだけを探す場合は、[QuickShopのコマンド一覧](../../quickshop/commands/)へどうぞ！

:::note[権限やサーバー設定について]
利用できるコマンドは、権限や設定によって変わります  
使えない場合はゲーム内のメッセージを確認してください
:::
