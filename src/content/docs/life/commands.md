チャット欄を開いて入力してください。
`プレイヤー名`や`名前`は、使いたい相手やホームの名前に置き換えます。例の日本語をそのまま入力する必要はありません。
プレイヤー名やホーム名は、入力途中でTabキーを押すと候補を確認できます。

スマホで表が画面に収まらないときは、表を左右に動かして確認できます。

:::note[利用できる機能について]
この一覧はhnmt-coreの実装を基にしています。サーバーへの導入状態・設定・権限によって、利用できる機能は変わります。
特に、新しく掲載した釣り・所有者記録・スコアボード操作の本番での利用可否は未確認です。
使えない場合は表示されたメッセージを確認し、不明な点は運営へお問い合わせください。
:::

## ホーム・スポーン

| コマンド | できること |
| --- | --- |
| `/home` | ホームの管理画面を開く。`/homes`も同じ |
| `/home 名前` | 指定したホームに移動する |
| `/sethome 名前` | 今いる場所をホームに登録する |
| `/spawn` | 共通スポーンに戻る |

登録・枠の購入・移動の取り消し条件は、[ホーム](../home/)・[スポーン](../spawn/)をご覧ください。
ホームの名前変更や削除は、ホームの管理画面から行います。

## テレポート申請

| コマンド | できること |
| --- | --- |
| `/tpa プレイヤー名` | 相手のところへ移動する申請を送る |
| `/tpahere プレイヤー名` | 相手をこちらへ呼ぶ申請を送る |
| `/tpaccept`・`/tpaccept プレイヤー名` | 届いた申請を承認する |
| `/tpdeny`・`/tpdeny プレイヤー名` | 届いた申請を拒否する |
| `/tpcancel` | 自分が送ったテレポート申請・移動待機を取り消す |

誰が移動するかや有効期限は、[テレポート申請](../tpa/)で確認できます。
相手を確かめてから承認しましょう！

## 個別メッセージ・無視設定

| コマンド | できること |
| --- | --- |
| `/msg プレイヤー名 本文` | オンラインの相手へ個別メッセージを送る |
| `/reply 本文` | 直前の個別メッセージの相手へ返信する |
| `/ignore プレイヤー名` | 無視設定を登録・解除する |
| `/ignore list` | 無視設定の一覧を見る |

`/msg`は`/m`・`/tell`・`/w`・`/whisper`、`/reply`は`/r`とも入力できます。
同じ操作の短い名前で、使い方や権限は変わりません。

無視設定の相手は、参加履歴があればオフラインでも指定できます。
送受信の条件と解除方法は、[個別メッセージ](../messages/)をご覧ください。
TownyChatの町チャットなどは、[チャットの案内](../../town/chat/)にまとめています。

## 釣り・魚の図鑑

| コマンド | できること |
| --- | --- |
| `/zukan` | 自分の魚の図鑑を開く |
| `/zukan プレイヤー名` | 指定した人の魚の図鑑を開く。参加履歴があればオフラインでも指定可能 |

図鑑は公開されていて、公開・非公開の切り替えはありません。
詳細画面では重さを基準にしたランキングも確認できます。
[クーラーボックス](../../fishing/cooler/)は右クリックで開き、Shift＋右クリックで自動回収を切り替えます。専用コマンドはありません。
[釣りを始める](../../fishing/getting-started/)・[魚と図鑑](../../fishing/zukan/)をご覧ください。
竿や餌は作業台で作り、料理はまな板を右クリックして行います。専用の釣り開始・調理コマンドはありません。

## アイテムの所有者を記録する

対象のアイテムをメインハンドに持ってから使います。

| コマンド | できること |
| --- | --- |
| `/ig create` | 手に持ったアイテムに、自分を所有者として記録する |
| `/ig info` | 記録されている所有者を確認する |
| `/ig remove` | 自分が付けた所有者の記録を外す |

すでにほかの人の所有者記録が付いている場合、自分の名前では上書きできません。
他人の記録を外せるのは、専用の管理権限を持つ人だけです。
手が空のときや記録がないときは、その理由が表示されます。

:::caution[所有者の記録は、アイテムの保護ではありません]
名前を記録しても、受け渡し・使用・紛失を防いだり、なくした物を自動回収したりする機能はありません。
大切な物は、自分で保管場所や取り扱いを確認してください。
:::

## スコアボード

| コマンド | できること |
| --- | --- |
| `/hnsb` | 自分のスコアボードの表示状態と、利用できる操作を見る |
| `/hnsb toggle` | 右側のスコアボードの表示・非表示を切り替える |

表示の選択は、再参加しても引き継がれます。
機能が無効・連携が利用不可・非表示対象のワールドなどでは、表示できないことがあります。

## Tips・おみくじ

| コマンド | できること |
| --- | --- |
| `/tips on` | Tipsの自動表示を再開する |
| `/tips off` | Tipsの自動表示を止める |
| `/tips reset` | 個別に隠したTipsを戻す |
| `/omikuji` | 1日1回のおみくじを引く・今日の結果を見る |

特定のTipsだけを隠すときは、表示されたTipsの非表示ボタンを押してください。
[Tips](../tips/)・[毎日のおみくじ](../omikuji/)で、表示設定や遊び方を確認できます。

## 導入準備中：チュートリアル

次のコマンドは、新しいチュートリアルの更新導入後に利用できます。
ボタンや案内の進み方は、[行動に合わせたチュートリアル](../../start/tutorial/)をご覧ください。

| コマンド | できること |
| --- | --- |
| `/tutorial` | 今進められる案内をもう一度表示する |
| `/tutorial off` | すべてのチュートリアルの自動表示を止める |
| `/tutorial on` | 自動表示を再開する |
| `/tutorial guide` | ガイドブックを開く |
