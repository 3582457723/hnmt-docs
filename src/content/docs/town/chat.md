話したい相手に合わせて、チャットの範囲を選べます！

## 全体と町の会話

TownyChatの標準的なチャンネルは、次のコマンドで切り替えられます

| コマンド | 会話の範囲 |
| --- | --- |
| `/g` | 全体チャット |
| `/tc` | 自分の町のチャット |
| `/nc` | 自分の国家のチャット |
| `/ac` | 自分の国家と同盟関係にある国家とのチャット。チャンネルと権限が有効な場合 |
| `/l`・`/lc` | 近くの人向けのローカルチャット。距離・ワールドの範囲は設定による |

町や国家に所属していない場合は、そのチャンネルを使えません  。
チャンネル名やコマンドは設定によって変わる場合があります。

## 一度だけ別の範囲に送る

`/tc メッセージ` のように本文を続けると、そのチャンネルに一度だけ送れます  。
送信前に、誰に届くチャンネルなのか確認しておきましょう。

例えば`/tc はじめまして！ 家を建てられる土地はありますか？`と送れば、町の人に相談できます。
`/tc`だけで切り替えた場合は、その後に普通に入力する会話も町チャットになります。
全体へ戻すときは`/g`を使ってください。

## 受信するチャンネルを確認する

| コマンド | できること |
| --- | --- |
| `/channel`・`/channel ?` | チャンネル操作のヘルプを見る |
| `/channel list` | 自分が受信できるチャンネルと、参加状態を確認する |
| `/channel join チャンネル名` | チャンネルの受信に参加する |
| `/channel leave チャンネル名` | チャンネルの受信から抜ける。離脱が許可されている場合のみ |
| `/channel soundtoggle チャンネル名` | 自分に鳴る、そのチャンネルの通知音を切り替える |
| `/resident toggle ignoreotherchannels` | 選択中以外の、無視できるチャンネルの受信を抑える・戻す |

`/ch`は`/channel`の短縮形です。
`/join チャンネル名`・`/leave チャンネル名`も用意されていますが、別プラグインと重なる場合は長い形式を使ってください。

`チャンネル名`には`/channel list`に表示された名前を使います。
例えば`general`と表示されたチャンネルの音を切り替えるなら`/channel soundtoggle general`です。
音が設定されていないチャンネルでは、切り替えても音は鳴りません。

`/channel join`は「受信に参加」、`/g`や`/tc`は「普段の送信先を選ぶ」操作です。
同じ意味ではありません。
チャンネルを受信できても発言権限がない場合や、町・国家への所属が必要な場合もあります。

## 会話が届かないとき

自分の送信先と、相手の受信状態を確認してください。
ローカルチャットなら距離、町・国家チャットなら所属も確認します。
ミュートや短時間の連投制限で送れない場合は、表示された理由に従ってください。

`/channel mute`・`unmute`・`mutelist`と、`/townychat reload`は管理・モデレーション向けのため、一般向けの操作手順には含めていません。
個別メッセージの無視設定は、TownyChatの受信チャンネルとは別の機能です。

## ひとりに話しかける

個別の相談には、[個別メッセージ](../../life/messages/)を使えます  。
`/msg プレイヤー名 メッセージ` で、相手だけに送れます。

## チャットをコピーする

日ノ本鯖のTownyChatでは、チャットをクリックすると、名前やチャンネル名を含めた表示全体をコピーできます
