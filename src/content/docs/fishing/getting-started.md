川でのんびり竿を出したり、船竿を作って海の大物に挑んだり。
日ノ本鯖の釣りでは、サイズの違う魚を集め、図鑑に記録し、料理まで楽しめます！

:::note[このガイドの基準]
ガイドは、hnmt-coreに実装された機能と初期設定を基にしています。
本番サーバーでの有効状態や設定は未確認です。レシピや魚の出やすさなどが変更されている場合は、ゲーム内の案内を優先してください。
:::

## 最初の1匹を釣ってみよう

1. 作業台で**竹3個・糸2個**を使い、竹竿を作ります。材料の配置は自由です
2. 川や浅い海へ行き、竿を持って水面へ右クリックします
3. 浮きの周りに泡が出たら、当たりが近い合図です
4. <strong>「！ 右クリックで巻く！」</strong>が出たら、右クリックします
5. 駆け引きが始まったら、**「巻け！」の間に右クリック、「待て！」の間は手を止めます**
6. 引き寄せのゲージを満たすと釣り上げ成功！ `/zukan`で記録を見てみましょう

餌がなくても釣れます。まずは竹竿で操作に慣れてから、[竿と餌](../gear/)をそろえてみませんか？
通常の釣竿も、初期設定では竹竿と同じ範囲の魚を狙えます。

## 2つのゲージを見る

| 表示 | 意味 | 操作の目安 |
| --- | --- | --- |
| 引き寄せ | 魚をどれだけ近づけたか | 「巻け！」の合図に合わせて巻く |
| 張力 | 糸にかかっている負荷 | 上がりすぎたら巻くのをやめる |

魚は「暴れる」と「疲れた」を繰り返します。
疲れた間は巻きやすく、暴れている間に巻くと張力が大きく上がります。
当たりに素早く反応すると「ジャストヒット」になり、少し有利に始められます！

:::tip[連打よりも、合図に合わせて巻きましょう]
張力が上限を超えると糸が切れ、時間内に引き寄せられない場合も逃げられます。
駆け引きで逃げられたときは、預けていた餌が戻り、その釣り上げによる竿の耐久は減りません。
:::

通常の魚や宝物・ゴミが釣れることもあります。
カスタムの魚に置き換わらない釣果では、この駆け引きが始まらない場合があります。

## 場所を変えてみる

釣れる魚は、**針がある場所のバイオーム**で変わります。
海面からの深さで「浅い海」「深い海」を分けているわけではありません。

| 釣り場 | 目安 |
| --- | --- |
| 川 | 川や凍った川。海以外のバイオームにある水辺も同じ扱い |
| 浅い海 | 通常の海、暖かい海、冷たい海などの海バイオーム |
| 深い海 | 深い海・深い冷たい海など、深海のバイオーム |

**深い海の魚を狙うには船竿が必要です。**
竹竿や渓流竿・磯竿を深海で使うと、浅い海の魚が対象になります。

時間帯・天気・満月の夜によっても、魚の出やすさや待ち時間が変わります。
[魚と図鑑](../zukan/)で、釣りたい魚の場所やヒントを探してみましょう。

## 魚が増えてきたら

[クーラーボックス](../cooler/)を持つと、専用の魚をまとめて運べます。
自動回収をオンにすれば、自分で釣った魚を箱へ入れられます。長く釣りを楽しみたいときに便利です！

## 釣り続けると待ち時間が長くなることがあります

短い間にたくさん釣ると、魚が警戒し、次の当たりまでの待ち時間が長くなります。
初期設定では、直近30分に釣った専用の魚が60匹を超えると始まります。
超過1匹につき待ち時間の倍率が10％ずつ増え、最大6倍になります。

例えば直近30分に61匹なら1.1倍、70匹なら2倍が目安です。
竿や時間帯などの補正とは別に掛かるため、実際に待つ秒数がいつも同じになるわけではありません。

しばらく釣りを休むと、古い釣果が集計から外れ、少しずつ元に戻ります。
その間に料理や町づくりを楽しむのもよいですね！ 退出して入り直すだけではリセットされません。

## 音や見た目について

待ち時間や駆け引き中には、本人にBGMが流れます。
大きすぎる場合は、クライアントの「ジュークボックス／ノートブロック」の音量を調整してください。

初めての魚や大物などを釣ると、画面や音でも知らせます。
水柱や花火の演出は近くの人にも見え、一部の大物は全体にも告知されます。

リソースパックで、魚・竿・料理の専用の見た目を表示できます。
パックが適用されていないと、通常の魚などの見た目になる場合があります。アイテムの名前と説明も確認してください。
受け取り方や手動で入れる方法は、[リソースパックの案内](../resource-pack/)をご覧ください。

魚・竿・餌・料理などの名前や説明は、持ち主のクライアントの言語に合わせて日本語・英語へ切り替わります。
他の人から受け取った直後は、切り替わるまで少し待つことがあります。

## うまく釣れないとき

| 困ったこと | 確認すること |
| --- | --- |
| すぐ糸が切れる | 「待て！」の間は巻かず、張力を下げる |
| 深海でマグロが釣れない | 船竿を使っているか、針の位置が深海バイオームか確認する |
| いつも同じ魚が釣れる | 場所・時間帯・餌を変えてみる。特定の魚が必ず釣れるわけではありません |
| 図鑑に追加されない | 通常のタラなどは記録対象外。名前とサイズ付きの魚か確認する |
| 当たりまでの待ち時間が長くなった | 直近の釣果による警戒の影響かもしれません。少し休んでから試してみる |
| `/zukan`で読み込みに失敗する | 少し待って再実行し、繰り返す場合は表示された内容を運営へ伝える |

釣った魚は、[まな板で料理](../cooking/)にも使えます！
