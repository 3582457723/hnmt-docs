釣った魚で持ち物がいっぱいになってきたら、クーラーボックスを用意してみましょう！
専用の魚をまとめて持ち運べます。小から中、大へ強化すると、同じ箱でより多くの魚を運べます。

材料や容量は初期設定です。サーバーの設定が異なる場合は、ゲーム内の案内を優先してください。

## 作る・大きくする

作業台に材料を置いて作ります。配置は自由で、1回につき1個できます。

### 小（9マス）

材料：樽1個・氷4個・鉄インゴット1個

### 中（27マス）

材料：小のクーラーボックス1個・氷4個・鉄インゴット2個

### 大（54マス）

材料：中のクーラーボックス1個・氷塊4個・鉄インゴット4個

中・大は、指定された段階のクーラーボックスを材料に使います。普通の樽では代用できません。
強化すると、中の魚を引き継げます。中・大への強化は、クラフターではなく作業台で行ってください。

## 開いて魚を入れる

次のどちらかの方法で開けます。

- ボックスを手に持ち、右クリックする
- インベントリを開き、カーソルに何も持たずにボックスを右クリックする

開いた画面には、名前やサイズが付いた専用の魚だけを入れられます。
通常のタラ・サケ、餌、完成した料理、ほかのボックスなどは入れられません。
料理に使うときは、先に魚を取り出して自分の持ち物へ戻してください。

ボックスは樽のように設置する道具ではありません。
手に持ってブロックを右クリックした場合も、置く代わりにボックスを開きます。

## 釣った魚を自動で回収する

1. ボックスを手に持って、Shiftを押しながら右クリックします
2. アイテムの説明が「自動回収: オン」になり、光ることを確認します
3. そのボックスを持ち物に入れたまま釣ると、自分が釣った魚が入ります

インベントリ内のボックスを、カーソルが空の状態でShift＋右クリックしても切り替えられます。
同じ操作でもう一度押すとオフです。初期状態はオフで、設定は箱ごとに切り替えます。

複数ある場合は、ホットバーから持ち物の順に、入れられるボックスを探します。オフハンドは最後です。
自動回収でも、図鑑やランキングの記録、大物の通知は通常どおり行われます。

:::tip[自動回収されないとき]
箱が満杯・ほかの人が使用中・自動回収オフの場合や、対象の箱を持っていない場合は通常の釣果として扱われます。
魚が必ず箱へ入るわけではないので、自分の持ち物と釣り場の落とし物も確認してください。
通常の魚・宝物・ゴミは、自動回収の対象外です。
:::

## 箱をなくさないようにしましょう

:::caution[中に魚を入れたまま、箱を捨てないでください]
箱のアイテムをなくすと、中の魚を取り出せなくなります。
新しい箱を作っても、なくした箱の中身が移るわけではありません。
大切な魚を入れた箱は、安全な場所に保管しましょう。
:::

## 困ったとき

| 状況 | 確認すること |
| --- | --- |
| 中・大を作れない | 正しい段階のボックスを材料にし、作業台で作っているか確認する |
| インベントリから開けない | カーソルに持っているアイテムを戻してから右クリックする |
| 魚を入れられない | 通常の魚や料理ではなく、専用の魚か確認する |
| 自動回収されない | 箱の説明、空き、使用中かどうかを確認する |
| 使用中と表示される | その人が箱を閉じてから、もう一度試す |

統合版のタップ操作や、Shift＋右クリックに相当する操作は実機未確認です。
操作できない場合は運営へ相談してください。
