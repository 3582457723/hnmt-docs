同じ魚でも、釣るたびにサイズが違います。
初めての1匹を見つけたり、自分の最大記録を更新したりしながら、図鑑を埋めてみましょう！

## 図鑑を開く

| コマンド | できること |
| --- | --- |
| `/zukan` | 自分の魚の図鑑を開く |
| `/zukan プレイヤー名` | 指定した人の図鑑を開く |

図鑑には、釣った数・最大の長さ・最大の重さ・初めて釣った日が残ります。
長さと重さは別々の記録です。同じ長さでも重さに個体差があるので、次の1匹で記録が伸びるかもしれません！
釣っていない魚は「？？？」と表示され、生息場所のヒントを読めます。

:::note[図鑑はほかの人からも見られます]
図鑑の記録は公開されます。公開・非公開の切り替えはありません。
過去に参加した人なら、オフラインでも名前を指定して見られます。
:::

## 画面の使い方

| 操作 | できること |
| --- | --- |
| 場所の絞り込み | すべて → 川 → 浅い海 → 深い海の順で切り替える |
| 発見の絞り込み | すべて → 釣った魚 → まだの魚の順で切り替える |
| 並び | 標準の順 → 釣った魚を先に → レア度の高い順で切り替える |
| 釣った魚をクリック | 魚の説明、サイズの目安、出やすい場所や状況、記録、サイズランキング、作れる料理を見る |
| 一覧へ戻る | 絞り込みや並びを保ったまま、魚の一覧へ戻る |
| 前のページ・次のページ | 複数ページあるときに切り替える |
| 閉じる | 図鑑を閉じる |

まだ釣っていない魚の詳細画面は開けません。
絞り込みや並びは、その画面を閉じると初期状態に戻ります。

図鑑は6段で、最上段に操作ボタン、残りの45マスに魚が並びます。
レア度は、魚の名前の色と★で見分けられます。★1が青、★2が緑、★3が橙です。未発見の魚は灰色です。
12種類をすべて集めると、最上段の飾りが金色になり、集めた数の本が光ります！

未発見の魚にカーソルを合わせると、場所・時間帯・天気・向いた竿のヒントを読めます。
魚によって表示される項目は異なります。まだ見つけていない魚を探すときに使ってみてください。

## 釣れる魚と場所

サイズ・生息場所・レア度は初期設定です。
場所は[針があるバイオーム](../getting-started/#場所を変えてみる)で判定し、深海の魚には船竿が必要です。

| 魚 | 通常のサイズ | 場所 | レア度 |
| --- | --- | --- | --- |
| ウナギ | 40〜100cm | 川 | ★★ |
| サーモン | 50〜90cm | 川・浅い海 | ★ |
| コハダ | 8〜16cm | 川・浅い海 | ★ |
| コノシロ | 17〜30cm | 川・浅い海 | ★★ |
| タイ | 30〜100cm | 浅い海 | ★★ |
| ヒラメ | 40〜80cm | 浅い海 | ★★ |
| サバ | 25〜50cm | 浅い海 | ★ |
| ハマチ | 40〜79cm | 浅い海・深い海 | ★★ |
| ブリ | 80〜130cm | 浅い海・深い海 | ★★★ |
| イカ | 20〜60cm | 深い海 | ★★ |
| カンパチ | 50〜150cm | 深い海 | ★★★ |
| マグロ | 80〜300cm | 深い海 | ★★★ |

コハダは17cmからコノシロ、ハマチは80cmからブリになります。
図鑑では別々の魚として数えます。大きな1匹が釣れたら、名前も見てみてください！

図鑑の「出やすさ」は目安です。時間帯・天候・竿・餌によって実際の釣れやすさは変わり、表示だけで次の釣果は決まりません。

## 大物の記録を狙う

★3の魚のうち、決められたサイズ以上のものが「大物」です。
大物の基準は図鑑の詳細画面で確認できます。

自己ベストを更新すると本人に通知され、一部の大物は全体にも告知されます。
大物を[料理](../cooking/)に使うと、初期設定では満腹度の回復量が少し増えます。
記録を残してから、食事にする楽しみもありますね！

## 通常より大きい「特大」の魚

まれに、上の表にある通常サイズを超える魚が釣れます。
これが「特大」です。初期設定では、専用の魚が決まるときの0.5％で発生します。

特大の抽選には、竿・餌・時間帯などの補正は付きません。
「大物」はレア度とサイズによる判定、「特大」は通常のサイズ範囲を超える抽選なので、同じ意味ではありません。

## サイズランキングを見る

釣った魚の詳細画面から、その魚のサイズランキングを確認できます。
名前は「サイズランキング」ですが、順位の基準は<strong>長さではなく重さ</strong>です。

- 上位5人の名前・重さ・その記録を釣った日が表示されます
- 1人につき、その魚で釣った最大の重さが対象です。オフラインの人も載ります
- コハダとコノシロ、ハマチとブリは、それぞれ同じ系統としてまとめて集計します
- 同じ重さなら同順位です。例えば1位・1位・3位となり、同じ重さの中では先に釣った人が上に並びます
- 上位の一覧に続いて、図鑑の持ち主の順位も表示されます。他の人の図鑑なら、その人の順位です

重さの記録がない場合は「未記録」と表示されます。
重さの機能より前の釣果には、保存された長さから推定した重さが入る場合があります。

ランキングの集計に失敗しても、図鑑そのものは開けます。
「集計できませんでした」と表示された場合は、少し待ってから開き直してください。

## 名前や記録が見つからないとき

- 名前は、相手が最後に参加したときのMCIDで指定します。Tab補完も使えます
- 参加履歴にない人は指定できません。同じ名前の履歴が重複する場合は、相手がオンラインのときに試してください
- 通常のタラ・サケなどは図鑑に記録されません。初期設定では、置き換え対象の20％は通常の魚のまま釣れます
- もらった魚を持っただけでは、自分で釣った記録にはなりません
- 読み込みに失敗した場合は少し待ってから試し、繰り返す場合は運営へ伝えてください
