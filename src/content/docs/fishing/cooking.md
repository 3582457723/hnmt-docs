釣った魚を、そのまましまっておくのはもったいない！
まな板を用意すると、刺身や握り、丼、温かい魚料理を作れます。

このページの材料・個数・回復量は初期設定です。
使うのは、名前やサイズが付いた専用の魚です。通常のタラ・サケなどは、この厨房で選ぶ魚の対象にはなりません。

## まな板を用意する

1. 作業台に**竹の板材3個・鉄インゴット1個**を置き、まな板を1個作ります。配置は自由です
2. 自分が設置できる場所に、まな板を置きます
3. **スニークせずに右クリック**すると、厨房の画面が開きます

:::note[設置すると製図台の見た目になります]
まな板は専用のアイテムを設置して使います。普通の製図台を置いただけでは厨房を開けません。
リソースパックで変わるのは持ち物のアイコンで、設置後のブロックは製図台の見た目です。
サバイバルで壊すと、まな板のアイテムを回収できます。
:::

町の中では、設置や利用が許可された場所を使ってください。
[土地の権限](../../towny/permissions/)も確認しておくと安心です！

## 料理を作る

1. 料理したい魚を、自分の持ち物に入れておきます。クーラーボックスの中の魚は、先に取り出してください
2. まな板を右クリックし、厨房の一覧から魚を選びます
3. 作りたい料理を選びます。魚によって選べる料理が違います
4. 表示された道具をクリックし、「切る」「握る」などの手順を進めます
5. 焼く・煮る工程は、クリックしてから少し待ちます。終わったら次の手順へ進みます
6. 完成すると材料が減り、料理を受け取れます

材料は、**完成したとき**に使います。途中で画面を閉じても、未完成の料理の材料は減りません。
ただし、精米やいくら作りはそれぞれ独立した加工です。加工が成功した時点で、元の材料を使います。

:::tip[初めてなら、サーモンの刺身から]
サーモンを選び、刺身の手順で道具をクリックしてみましょう！
米を使わないので、魚とまな板だけで試せます。握りや丼を作りたくなったら、次の精米も使ってみてください。
:::

## 米を作る

小麦を持って厨房を開き、<strong>「精米する」</strong>を押します。
初期設定では、小麦3個が米1個になります。

精米では、持っている小麦から作れる分をまとめて加工します。
例えば小麦10個なら、9個を使って米3個を作り、小麦1個が残ります。
使いたい分だけの小麦を持って操作すると分かりやすいです。

握り・丼は、魚などの主材料1個に加え、米1個を使います。
必要な米が足りないと、その料理を選べません。

## いくらを作る

専用のサーモンを持って厨房を開き、サーモンを選んで<strong>「いくらをほぐす」</strong>を使います。
初期設定では、サーモン1匹からいくら2個を作れます。

いくらを作ったら一覧に戻り、いくらを選んで丼にできます。
いくら丼1個には、いくら1個と米1個を使います。

## 作れる料理

初期設定では32品です。魚に合う料理だけが厨房に表示されます。

| 料理 | 使える魚・材料 | 米 |
| --- | --- | --- |
| 刺身（9品） | サーモン・タイ・ヒラメ・ハマチ・ブリ・イカ・カンパチ・マグロ・サバ | 不要 |
| 握り（11品） | コハダ・サーモン・タイ・ヒラメ・ハマチ・ブリ・イカ・カンパチ・マグロ・サバ・ウナギ | 1個 |
| 丼（5品） | マグロ・サーモン・タイ・ウナギ・いくら | 1個 |
| 焼き魚（4品） | サーモン・ブリ・ウナギ・コノシロ | 不要 |
| 煮魚（2品） | サバ・ヒラメ | 不要 |
| 汁物（1品） | タイ | 不要 |

料理は生の魚より満腹度を多く回復します。
初期設定での回復量は、刺身3・握り4・焼き魚／煮魚／汁物5・丼7です。
これは満腹度の数値で、例えば4なら肉アイコン2個分に当たります。大物の魚を使うと、さらに1増えます。

## 料理の見た目を楽しむ

[3D版のリソースパック](../resource-pack/)では、丼の深さや皿の縁、盛り付けたご飯・魚・薬味も立体で表示されます。
見た目が変わらない場合は、パックの読み込みとアイテムの名前を確認してください。

## 料理できないとき

| 状況 | 確認すること |
| --- | --- |
| 厨房が開かない | 専用のまな板か、スニークしていないか、設置場所の利用が許可されているか確認する |
| 魚の一覧が空 | 専用の魚を持ち物に入れる。通常の魚やチェストの中の魚は対象外 |
| 握りや丼を選べない | 米を持ち物に入れ、画面に出る必要数を確認する |
| 作りたい料理がない | その魚で作れる料理か、表と画面の候補を確認する |
| 材料が足りないと表示される | 選んだ種類・サイズの魚と米が持ち物に残っているか確認する |

米・いくら・完成した料理は、普通の作業台の材料や羊の染色には使えません。
アイテムの名前と説明を見て、通常の材料と分けて扱ってください。
