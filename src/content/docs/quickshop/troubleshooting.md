うまく操作できないときは、まずチャットに出た理由を確認しましょう。
同じ操作を何度も繰り返す前に、当てはまる項目を見てみてください！

## お店を作れない

1. サバイバルモードで、売りたいアイテムをメインハンドに持っているか確認します。
2. 対象がチェストで、すでに別のお店になっていないか確認します。
3. 作成を許可された場所か、町の土地の権限も確認します。
4. 作成費がある場合は、残高を確認します。
5. お店の数・商品・価格に制限がないか、表示された理由を読みます。

クリック操作が変わっている場合は、[作成コマンド](../creating/#クリックで作れないとき)も確認できます。
権限や禁止商品の制限が理由なら、コマンドを変えても回避できるとは限りません。

## お店から買えない

| 確認すること | 対処 |
| --- | --- |
| お店は「販売」か | 買取店へ商品を買いに行っていないか確認する |
| 自分のお金は足りるか | 数量と金額を見直す |
| 自分のインベントリに空きはあるか | 品物を受け取れる空きを作る |
| お店の在庫はあるか | 数量を減らすか、補充を待つ |
| お店は休業中ではないか | 持ち主に再開予定を聞く |

数字を入力しても反応がない場合は、もう一度お店をクリックし、数量を聞かれるところから確認してください。

## お店に売れない

| 確認すること | 対処 |
| --- | --- |
| お店は「買取」か | お金を受け取りたい場合は買取店を使う |
| 対象の商品を持っているか | 売りたい商品を自分のインベントリに入れる |
| 商品の内容は一致しているか | 名前・耐久値・エンチャントなどをプレビューと比べる |
| お店に空きはあるか | 持ち主に回収をお願いする |
| お店側のお金は足りるか | 持ち主に確認するか、別のお店を探す |

:::note[同じ見た目でも、同じ商品とは限りません]
エンチャント・名前・耐久値などの照合方法はサーバー設定によって変わります。
アイテムを加工して合わせようとする前に、プレビューで違いを確認しましょう。
:::

## 管理パネルを開けない

標準操作は、**お店の看板を右クリック**です。
設定によって操作が変わっている場合は、実際の案内に従ってください。

自分のお店か、管理権限を持っているお店かも確認します。
スタッフに登録されていても、すべての変更ができるとは限りません。

価格変更などのコマンドで「ショップを見ていない」と表示されたら、対象のチェストへ視点を合わせ直してください。

## 補充・回収ができない

QuickShopのスタッフ設定に加え、Townyなどの保護設定が関係する場合があります。

[共同管理と土地の権限](../staff/#土地の権限も確認する)を確認し、まずはその区画の所有者や町の担当者に相談してください。
**町全体のチェスト権限を広く開放して解決しようとしない**ことが大切です。

## お店の検索で見つからない

`/qs find diamond`のように、英語のアイテム名で試してください。
検索距離・表示件数・再使用間隔・お店の公開範囲などで、結果が変わります。

お店が見つからないだけでは、削除されたとは判断できません。
場所が分かる場合は、現地の表示も確認しましょう。

## 取引について相談したい

次の情報を添えると、確認が進めやすいです。

- お店のワールドと座標
- 取引したおおよその日時
- 商品・数量・表示されていた金額
- 販売店か買取店か
- チャットに出たメッセージ
- 困っている状況が分かるスクリーンショット

自分のお店なら、権限がある場合に`/qs history`で履歴も確認できます。
関係のない会話や個人情報が写った画像は、そのまま公開しないでください。
