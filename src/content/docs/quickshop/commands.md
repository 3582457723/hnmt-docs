入力するコマンドを忘れたときに使ってください！
初めてのお店づくりは、[作成の手順](../creating/)に沿って進めると分かりやすいです。

## コマンドの読み方

このガイドは短縮形の`/qs`で説明しています。
標準設定では`/quickshop`でも同じ操作ができます。

`金額`・`個数`・`MCID`は、その文字を入力するのではなく、自分の設定したい値に置き換えてください。
例の`Alex`も相手のMCIDに置き換えます。

:::note[管理コマンドは対象のお店を見て実行]
価格や売買の向き、スタッフなどを変更するときは、対象のショップのチェストを見ながら操作します。
隣のお店を変更しないよう、実行後のメッセージと表示も確認してください。
所有者であっても、権限や設定によって使えない機能があります。
:::

## 調べる・作る

| コマンド | 使い方・入力例 |
| --- | --- |
| `/qs help` | 利用できるコマンドを確認する |
| `/qs find 商品名` | お店を検索。例：`/qs find diamond` |
| `/qs info` | 見ているお店の情報を確認する |
| `/qs create 金額` | 手に持った商品で、見ているチェストに販売店を作る。例：`/qs create 10` |

検索は[買い物の案内](../trading/#商品名でお店を探す)、作成は[初めてのお店を作る](../creating/)で詳しく説明しています。

## 値段・売買・商品を変更する

| コマンド | 操作 |
| --- | --- |
| `/qs price 金額` | 価格を変更。例：`/qs price 20` |
| `/qs sell` | お客さんに品物を売る販売店へ変更 |
| `/qs buy` | お客さんから品物を買う買取店へ変更 |
| `/qs freeze` | 休業・再開を切り替える |
| `/qs size 個数` | まとめ売りの取引単位を変更。機能が有効な場合のみ。例：`/qs size 16` |
| `/qs item` | 手に持ったアイテムへ商品を変更する |
| `/qs name 名前` | お店に名前を付ける。例：`/qs name 木材のお店` |
| `/qs toggledisplay` | 商品の展示表示を切り替える |

:::caution[商品や数量の変更後は、在庫と価格を確認]
`/qs item`は商品の種類を変える操作で、補充ではありません。
今ある在庫が新しい商品に合っているか確認してください。
`/qs size`で取引単位を変えた場合も、価格を見直しましょう。
:::

価格変更などの手数料や、休業・再開の注意点は[お店の管理と休業](../managing/)にまとめています。

## スタッフを管理する

| コマンド | 操作 |
| --- | --- |
| `/qs staff add MCID` | そのお店のスタッフを追加 |
| `/qs staff del MCID` | そのお店のスタッフから1人を解除 |
| `/qs staff list` | スタッフ一覧を確認 |
| `/qs staff clear` | そのお店のスタッフを全員解除 |

[共同管理の注意点](../staff/#お店のスタッフを追加する)を読んでから登録してください。
サーバーの運営スタッフを設定するコマンドではありません。

## 取引履歴を見る

| コマンド | 操作 |
| --- | --- |
| `/qs history` | 見ているお店の取引履歴を表示 |
| `/qs history owned` | 自分が所有しているお店の取引履歴を表示 |
| `/qs history accessible` | 履歴を見る権限があるお店の取引履歴を表示 |

使える範囲や残っている記録は、権限と保存設定によって変わります。
履歴が見られない場合は、[困ったとき](../troubleshooting/#取引について相談したい)の情報を控えて運営へ相談してください。

## 所有者の変更・削除

| コマンド | 操作 |
| --- | --- |
| `/qs transferownership MCID` | 見ているお店の引き継ぎを申請 |
| `/qs transferownership accept` | 届いた引き継ぎ申請を承認 |
| `/qs transferownership reject` | 届いた引き継ぎ申請を拒否 |
| `/qs remove` | 見ているショップの登録を削除 |

:::caution[操作前に、対象と残っている品物を確認]
所有者の変更は[引き継ぎの手順](../staff/#お店の持ち主を変更する)、削除は[撤去の注意点](../managing/#お店を削除する)を確認してください。
一時的に取引を止めるだけなら、`/qs freeze`で休業できます。
:::

## この一覧の範囲

一般プレイヤーがお店を利用・運営するときによく使う操作を載せています。
運営専用の管理コマンドや、導入未確認のアドオンのコマンドは含めていません。
