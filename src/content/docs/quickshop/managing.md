お店を開いたあとも、値段や在庫は調整できます。
品切れの補充や、一時的なお休みもここで確認しておきましょう！

## 管理パネルを開く

標準設定では、自分のお店の**看板を右クリック**すると、チャットに管理パネルが開きます。
設定によっては管理GUIが開くため、画面の項目を選んでください。

管理できるのは、自分のお店か、操作する権限を持つお店です。
以下のコマンドは、変更したいショップのチェストを見ながら実行します。

## 値段を変える

```text
/qs price 20
```

対象のお店の価格を20に変更する例です。
管理パネルの価格変更から入力する方法もあります。
変更後は、商品と取引単位を含めて表示を確認してください。

:::caution[価格変更に手数料がかかる場合があります]
作成費とは別に、価格を変更するたびに手数料がかかる設定があります。
無料とは限らないため、金額を確認してから変更しましょう。
価格の下限・上限が設定されている場合は、その範囲内で入力してください。
:::

## 販売と買取を切り替える

| コマンド | お店の状態 | お店の持ち主のお金 |
| --- | --- | --- |
| `/qs sell` | お客さんに品物を売る | 受け取ります |
| `/qs buy` | お客さんから品物を買う | 支払います |

買取へ切り替えたら、チェストの空きと自分の残高を確認します。
販売へ切り替えたら、売る商品をチェストへ入れてください。

## 在庫と空きを管理する

販売のお店は、商品がなくなると売れなくなります。
同じ商品をチェストへ入れて補充してください。

買取のお店は、チェストがいっぱいになると買い取れなくなります。
買い取った品物を回収し、自分の残高も確認しておきましょう。

## まとめ売りの数量を変える

まとめ売りの機能と必要な権限が有効な場合に使えます。

```text
/qs size 16
```

対象のお店の取引単位を16個に変更する例です。
**チェストに16個補充するコマンドではありません。**

:::caution[数量を変えたら、価格も一緒に確認]
取引単位だけを変更すると、意図しない安売り・高額買取になるおそれがあります。
自動で希望の単価に調整されると思わず、数量と価格を見直してください。
:::

この機能が無効な場合、コマンドは使えません。
通常のお店でも、在庫を多めに補充しておくことはできます。

## お店の名前を付ける

```text
/qs name 木材のお店
```

取引の記録などでお店を識別しやすくする名前です。
名前の長さや変更費用に制限がある場合は、案内に従ってください。

## 一時的に休業する

```text
/qs freeze
```

取引を停止する操作です。
同じコマンドをもう一度実行すると、休業状態を解除します。
**繰り返すと停止と再開が切り替わる**ので、実行後のメッセージを確認してください。

:::tip[在庫の整理や、値段を見直すときに]
お店を残して作業したいときは、削除より休業が向いています。
再開するときに、売買の向き・商品・価格も確認しておくと安心です！
:::

## お店を削除する

対象のお店をよく確認してから実行します。

```text
/qs remove
```

:::caution[削除と休業は別の操作です]
削除するとショップの登録がなくなります。取り消せる前提で実行しないでください。
確認操作が必要かどうかも設定で変わるため、確認画面が必ず出るとは考えずに操作しましょう。
商品の扱いや返金について不明な場合は、先に運営へ相談してください。
:::

チェストを壊して撤去する場合も、設置場所や残っている品物を確認してください。
ほかの人と管理しているお店は、作業前に相談しておきましょう。
