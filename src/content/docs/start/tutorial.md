このページは、新しいチュートリアルの導入に向けた案内です。
本番サーバーでの利用開始は未確認です。以下のコマンドやボタンは、対応する更新の導入後に利用できます。

町に入れたけれど、次は何をすればいいの？ 初めてお店を作ったけれど、これで売れるのかな？
そんな場面で、**今の行動に合った次の一歩**をチャットで案内します！

すべてを一度に覚える必要はありません。
案内を見ながら操作しても、必要なところだけ読んで自分のペースで遊んでも大丈夫です。

## 案内の進め方

1. 町への参加やホームの登録など、対象の操作が成功すると案内が始まります
2. チャットに表示された説明を読み、必要な操作を行います
3. 操作の成功が確認されると、少し間を置いて次の手順へ進みます
4. 最後の説明を読み、<strong>［確認しました］</strong>を押すと、その案内は完了です

コマンドを入力しただけでは進みません。お金が足りないなどの理由で操作できなかったときは、表示された理由を確認してください。
案内が進まないときに、入金や購入を何度も繰り返す必要はありません。

同時に表示する案内は1つです。
初参加時は、道具の受け取りなどの案内が終わってから、行動に合わせたチュートリアルへ進みます。

### 町を作った後の例

| 順番 | 案内に沿って確認すること |
| --- | --- |
| 1 | `/town`で、自分の町の情報を見る |
| 2 | 町の銀行に運営資金を入れる。必要な金額は先に確認する |
| 3 | 必要なら町の領土を広げ、保護する範囲を確認する |
| 4 | 一緒に暮らす人がいれば、相手に相談して町へ招待する |
| 5 | 最後の説明を読んで、案内を完了する |

入金・領土の取得・招待は強制ではありません。
まだ準備ができていない手順は、<strong>［この手順をスキップ］</strong>で先へ進めます。
具体的な費用や操作は、[町の設立と領土](../../towny/town-land/)・[銀行と税金](../../towny/economy/)をご覧ください。

## ボタンでできること

| ボタン | 動作 |
| --- | --- |
| ［コマンドを入力］ | チャットの入力欄にコマンドの候補を入れる |
| ［この手順をスキップ］ | 操作せず、今の手順だけを飛ばす |
| ［確認しました］ | 最後の説明を確認し、その案内を完了する |
| ［チュートリアルを終了］ | **すべてのチュートリアルの自動表示を止める** |

:::tip[コマンドは、内容を確認してから送信しましょう]
［コマンドを入力］を押しても、その場で実行されるわけではありません。
金額・町名・プレイヤー名などを確認し、必要な部分を書き換えてから送信してください。
スキップボタンでも、お金を使ったり、土地の設定を変えたりすることはありません。
:::

:::caution[終了ボタンは、今の案内だけを閉じる操作ではありません]
［チュートリアルを終了］を押すと、初参加の案内を含め、すべてのチュートリアルの自動表示が止まります。
再開したくなったら、`/tutorial on`を使ってください。
初参加の案内を止めても、初心者キットの配布は取り消されません。

最後まで読んで1つの案内を完了した場合は、ほかのチュートリアルも引き続き表示されます。
:::

## もう一度読む・表示を切り替える

| コマンド | できること |
| --- | --- |
| `/tutorial` | 今進められる案内を、もう一度表示する |
| `/tutorial off` | すべてのチュートリアルの自動表示を止める |
| `/tutorial on` | 自動表示を再開し、途中の案内を続ける |
| `/tutorial guide` | ガイドブックを開いて読む |

ガイドブックは、自動表示を止めていても開けます。
`/tutorial guide`は本を読むためのコマンドで、アイテムをもう1冊もらう操作ではありません。

進行状況と表示設定は保存されます。途中で退出しても、次回参加時に続けられます。
一度完了した案内は、同じ操作をしても最初から繰り返し表示されません。
`/tutorial on`も、完了した案内をやり直すコマンドではありません。

## どんなときに案内が届く？

全部で20種類です。実際にその場面になったときに、関係する内容を案内します。
役職や所有者などの条件があり、町全体へ一斉に同じ案内が流れるわけではありません。

### 暮らしを始める

| きっかけ | 主な案内 |
| --- | --- |
| 初参加 | ガイドブックを開く・ホームを登録する |
| ホームを新しく登録 | ホーム画面を開く・実際に移動してみる |
| テレポート申請が届く | 移動する方向を確かめ、承認または拒否する |

[最初の一歩](../first-steps/)・[ホーム](../../life/home/)・[テレポート申請](../../life/tpa/)も参考にしてください！

### 町に参加する・運営する

| きっかけ | 主な案内 |
| --- | --- |
| 町を作成 | 町の情報・銀行・領土・住民の招待 |
| 町に参加 | 所属する町の情報・土地と暮らしのルール |
| 町長を引き継ぐ | 町の状態・運営資金の確認 |
| 町の領土を取得 | 境界と保護・土地の使い方 |
| 町の銀行へ入金 | 個人のお金と町の資金の違い |
| 住民を町へ招待 | 参加前の準備・住む場所の案内 |
| 土地を売り出す | 区画の範囲・価格・購入後の扱い |
| 土地を購入 | 自分の土地の情報・建築ルール |
| 土地の権限を変更 | 建築やアイテム利用など、許可する操作の違い |
| Townyのフレンドを追加 | フレンドに許可される土地の操作 |
| 町の役職を付与 | 町長向けに、任せる権限を確認 |
| 町の税金を変更 | 金額や方式の確認・住民への説明 |
| 町のスポーンを変更 | 到着場所の安全・利用条件 |
| 国家を作成 | 国家の情報・加盟する町との相談 |
| 町が国家に加盟 | 町長向けに、加盟先の情報と町への周知 |

町の保護や役職で迷ったら、[建築と操作の権限](../../towny/permissions/)を確認しましょう。
設定を変える前に、誰にどの操作を許可するのか確かめると安心です！

### お店を続ける

| きっかけ | 主な案内 |
| --- | --- |
| ショップを作成 | 管理パネル・価格変更・商品の補充 |
| 販売ショップが売り切れ | 管理パネルの確認・商品の補充 |

売り切れの案内は、在庫がある状態から売り切れになったことを確認したときに始まります。
[初めてのお店を作る](../../quickshop/creating/)・[お店の管理](../../quickshop/managing/)で、操作を詳しく確認できます。

## 案内が出ない・進まないとき

| 状況 | 確認すること |
| --- | --- |
| 自動表示を止めた | `/tutorial on`で再開する |
| チャットを見逃した | `/tutorial`で今の案内を表示する |
| 「進行中の案内はありません」と出る | 進められる案内がない状態です。読み物は`/tutorial guide`で開けます |
| コマンドを実行しても進まない | 操作が成功したか確認する。不要な手順はスキップする |
| ボタンが反応しない | 古い案内のボタンではなく、`/tutorial`で出し直した案内を使う |
| 町を抜けた後、町の案内が止まった | 所属や役職が必要な案内は、その条件を満たすまで保留されます |
| 読み込み中と表示される | 少し待ってから、もう一度試す |
| 保存・確認できないと表示される | 自動案内が保留されます。繰り返す場合は、表示内容を運営へ伝えてください |

表示設定の保存に失敗した場合は、次回参加時まで設定が残るとは限りません。
復旧後に改めて`/tutorial off`などで設定してください。

導入前に行った操作や、自動表示を止めている間の操作について、後からすべての案内が始まるわけではありません。
必要な説明は、このガイドの各ページからも確認できます。
