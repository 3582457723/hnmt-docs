初参加のときは、少しずつチュートリアルがチャットに流れます  
一度に覚えようとせず、案内を読みながら周りを見渡してみましょう！

## 道具を受け取る

「装備をお渡ししますね！」の案内に合わせて、初心者キットを受け取れます

| 配布されるもの | 個数 |
| --- | --- |
| 石の剣・ツルハシ・斧・シャベル | 各1本 |
| パン | 16個 |
| チェーンの防具 | 全身分 |
| ガイドブック | 1冊 |

空いている防具スロットには、チェーンの防具が装着されます  
すでに装備しているものがある場合は、手持ちの装備を優先します

:::note[インベントリに空きをつくりましょう]
持ち物がいっぱいのときは、配布できるまで待機します  
案内の途中で退出しても、次回参加で未完了の続きから進められます
:::

## ガイドブックを開く

本を手に持ち、右クリックで開いてみてください  
基本的な使い方を、ゲームの中でも確認できます！

## お気に入りの場所を覚えておく

暮らしたい場所が見つかったら、[ホーム](../../life/home/)として登録しておくと便利です  
迷ったときは、[スポーンへの移動](../../life/spawn/)も使えます

## 町を探してみる

Townyの町は、ほかのプレイヤーと暮らす拠点になります  
[町への参加と住民の操作](../../towny/residents/)で、町の探し方と参加の手順を確認しましょう！
